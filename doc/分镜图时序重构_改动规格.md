# 分镜图时序重构 · 改动规格

> 目标：将 `episode_storyboard` 拆分为脚本生成与分镜图绘制两个独立阶段，剧集级参考图前移至二者之间，使分镜图能参考剧集级场景/道具变化。

## 一、阶段链变更（16 → 17 阶段）

### 当前阶段链（16 阶段）

```
1  project_init
2  material_sorting
3  supervisor_extraction
4  global_character_tasks
5  global_character_art
6  global_prop_tasks
7  global_prop_art
8  global_scene_tasks
9  global_scene_art
10 episode_storyboard          ← 分镜脚本 + 分镜图（混合）
11 episode_character_ref       ← 妆造匹配清单
12 episode_prop_ref            ← 剧集级道具参考图
13 episode_scene_ref           ← 剧集级场景参考图
14 asset_sync
15 video_generation
16 delivery
```

### 目标阶段链（17 阶段）

```
1  project_init
2  material_sorting
3  supervisor_extraction
4  global_character_tasks
5  global_character_art
6  global_prop_tasks
7  global_prop_art
8  global_scene_tasks
9  global_scene_art
10 episode_storyboard_script   ← 分镜脚本生成（拆分前半）
11 episode_character_ref       ← 妆造匹配清单（前移，原11）
12 episode_prop_ref            ← 剧集级道具参考图（前移，原12）
13 episode_scene_ref           ← 剧集级场景参考图（前移，原13）
14 episode_storyboard_images   ← 分镜图绘制（拆分后半，新阶段）
15 asset_sync
16 video_generation
17 delivery
```

### 数据流验证（无循环依赖）

```
分镜脚本(10) ──→ 妆造清单(11)     [读 分镜脚本.json]
           ──→ 道具参考(12)      [读 分镜脚本.json + 全局基准]
           ──→ 场景参考(13)      [读 分镜脚本.json + 全局基准]
道具参考(12) ─┐
场景参考(13) ─┴→ 分镜图(14)       [读 分镜脚本.json + 剧集级参考图]
分镜图(14) ───→ 资产同步(15)      [复制 全局+剧集级参考图+分镜图 → temp/]
           ───→ 视频生成(16)      [读 temp/分组素材/]
```

## 三、不涉及改动的文件

| 文件 | 原因 |
|------|------|
| `generate_task_table.py` | 代码层面已支持 `--ref-images`，无需修改 |
| `expand_scenes_to_groups.py` | 纯机械拆分，与阶段拆分无关 |
| `run_pipeline.py` | 管线编排器，由 storyboard-director 按需调用，阶段拆分不影响其内部逻辑 |
| `validators.py`（storyboard） | 校验分镜 JSON 格式，与阶段无关 |
| `validate.py`（coordinator） | 仅校验 JSON 语法，不校验阶段数 |
| `prop-ref-generator/` `scene-ref-generator/` `roles-ref-generator/` | 输入依赖（分镜脚本.json）不变，只是执行时机提前 |
| `project-config.json` schema | `use_storyboard_images` 字段定义不变 |

## 四、风险与注意事项

1. **存量项目兼容**：已创建的 stages.json（16阶段）需要迁移脚本升级为 17 阶段。建议在 coordinator 的推进逻辑中增加兼容检测：若 stages 数为 16 且包含 `episode_storyboard`，自动插入 `episode_storyboard_images` 并重命名。
2. **use_storyboard_images=false 时**：`episode_storyboard_images` 阶段仍存在于 stages.json（17阶段），但 coordinator 标记为 `completed`（skipped），不 spawn 任何子 agent。阶段链不因配置缩短。
3. **多集循环**：video_generation 完成后如有下集，回到 `episode_storyboard_script`（原 `episode_storyboard`），需更新 stages.md 和 coordinator SKILL.md 中的循环引用。
4. **asset_sync 覆盖逻辑**：剧集级参考图与全局基准图同名时，剧集级应覆盖全局。需确保 coordinator 的复制操作使用 `-Force`（PowerShell）或 `cp -f`（bash）。
5. **AGENTS.md 规则**：`.opencode/` 下的文件修改应由 system-engineer 子 agent 执行。本规格文档供 system-engineer 作为执行依据。
