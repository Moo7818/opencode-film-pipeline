# 系统介绍

> 基于工作区实际架构（README.md、AGENTS.md、opencode.json、.opencode/rules/、各 skill、MCP 服务器）调研撰写。

## 一、项目信息（约400字）

本项目是基于 OpenCode AI Agent 框架构建的影视/动画制作管线工作区，目标是将原始剧本与创意需求，端到端转化为角色、场景、道具等视觉资产与可交付的 AI 视频成片。系统以多 Agent 协作为核心：orchestrator 主控负责意图识别与任务路由，下辖 Coordinator（项目统筹）、Producer（监制）、Writer（编剧）、Character-director / Set-designer / Prop-maker（角色/置景/道具导演）、Storyboard-director（分镜导演）、Art-director（美术指导）、Video-director（视频导演）等子 Agent，各自加载专业技能包独立执行，职责边界严格隔离、严禁越权。业务按标准化管线推进：项目初始化、剧本设定提取、全局视觉资产生成（角色三视图、场景参考图、道具四宫格）、三级分镜脚本拆解（场-组-镜）、剧集级参考图、参考帧生成与 LibTV 视频成片。工作区已沉淀 18 个技能包并承载 25 余个真实客户项目（宣传片、古装剧、MV、虚拟 IP 形象库等），配套一键部署脚本、凭证加密管理、Git 网络代理与编码规范，可支撑商业级影视生产。

## 二、技术实现方案（约400字）

技术架构以 opencode.json 为单一中枢，采用"路由分发 + 子 Agent 执行"模式：orchestrator 只传项目定位与阶段标识（spawn 模板限 3 行），禁止调研与越权，行为规则定义于 AGENTS.md 与 .opencode/rules/。项目元数据由独立 meta-server（FastMCP/stdio）管理，以 SQLite registry.db 为唯一数据源，提供 10 个 meta_* 工具覆盖全生命周期：17 阶段状态机初始化、阶段推进（前置校验+不可回退）、产物注册（自动哈希去重、类型枚举约束）、扫描归档、点路径配置合并与字段级 ACL（workspace_id 等仅 video-director 可写）。图像生成经 grsai-server（FastMCP）闭环执行——并发提交、轮询结果、本地下载、腾讯云 COS 持久化；视频生成接 LibTV 画布 CLI，由分镜组创建 video 节点并上传素材连线成片。Python 3.13 由 uv 管理，根虚拟环境与 MCP 子项目完全隔离，`uv run --no-sync` 跨平台启动并钉锁 uv.lock 保证复刻一致。生图任务统一遵循共享 image-generation.json Schema，配套 bootstrap 一键脚本与 CI 校验。
