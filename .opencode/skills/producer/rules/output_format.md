# 输出格式规范

> **提取范围声明**：本规范中的所有格式模板仅适用于**核心角色、核心场景、关键道具**。过场角色、龙套、无关紧要的道具不创建设定文件，直接跳过。判断标准见《剧本处理规范》"提取范围总则"。

## 目录结构总览

所有设定文件必须遵循以下扁平目录结构，禁止为每个实体创建独立子目录：

```
全局依赖/
├── 全局设定.md              ← 全局设定单一文件（世界观/时间线/人物关系/风格基调合并到此）
├── 角色设定/
│   ├── 角色设定.md          ← 入口索引（角色清单表格）
│   └── 具体设定/
│       ├── {角色名1}.md     ← 独立角色文档（扁平文件，非子目录）
│       └── {角色名2}.md
├── 场景设定/
│   ├── 场景设定.md
│   └── 具体设定/
│       └── {场景名1}.md
└── 道具设定/
    ├── 道具设定.md
    └── 具体设定/
        └── {道具名1}.md
```

> **🚫 严禁行为**：每个实体（角色/场景/道具）的独立文档必须直接以 `.md` 文件形式存放在 `具体设定/` 目录下，**不得**创建 `{实体名}/角色设定.md` 形式的子目录。即 `具体设定/校长.md` ✅，而非 `校长/角色设定.md` ❌。

> **🚫 全局设定严禁多文件**：所有全局设定内容必须合并到 `全局依赖/全局设定.md` **单一文件**中，用 markdown 章节组织。**不得**创建 `全局依赖/全局设定/` 子目录输出多个文件。

## 1. 角色设定格式

### 1.1 入口索引文档

保存到 `project/{项目名}/全局依赖/角色设定/角色设定.md`

```markdown
# 角色设定

## 角色清单

| 角色 | 身份 | 时代 | 参考文档 |
|------|------|------|---------|
| {角色名1} | {身份1} | {时代1} | [具体设定/{角色名1}.md](具体设定/{角色名1}.md) |
| {角色名2} | {身份2} | {时代2} | [具体设定/{角色名2}.md](具体设定/{角色名2}.md) |
```

### 1.2 独立角色文档

每个角色一个独立文件，保存到 `project/{项目名}/全局依赖/角色设定/具体设定/{角色名}.md`

```markdown
# {角色名} — 角色设定

## 基本信息

| 字段 | 内容 |
|------|------|
| 姓名 | {角色姓名} |
| 时代 | {所属时代} |
| 身份/职业 | {身份描述} |

## 性格特征

{性格描述，从剧本台词和行动中归纳}

## 外貌特征

{外貌描述，从剧本中提取，包含发型、脸型、体型、肤色等}

## 造型设计

{按妆造名分组，每组统合服装、妆容、发型、配饰描述。至少包含"默认"妆造（角色最常见的日常外观），其他妆造按剧情需要添加}

### 默认

{服装+妆容+发型+配饰，如：白衬衫+格子裙，清透裸妆，自然眉形，淡粉色唇彩，黑色长发自然垂落}

### {妆造名2}（如有）

{服装+妆容+发型+配饰，如：银色板甲，红色披风，战场粗眉，无妆容，束发}

## 动作习惯

{从剧本动作描述和台词引导中提取的关键动作习惯}

## 台词特征

{语言风格、常用表达、语气特点}

## 设计参考

| 字段 | 内容 |
|------|------|
| 视觉参考风格 | {视觉风格关键词，如"3D卡通，皮克斯风格"/"真人摄影，写实"/"吉卜力风格"等。用于下游参考图生成时判断质感类型} |

## 参考来源

- 剧本原文引用：{从剧本中提取这些信息的原文引用}
- 网络参考资料：{如果通过联网搜索补充了历史信息，在此标注搜索关键词和来源}【有则写，无则省略此条】
```

## 2. 场景设定格式

> **场景定义**：每个场景文件对应一个**独立的物理空间**（一个房间、一栋建筑、一个户外地点）。同一物理空间中不同焦段/区域（如"舞台中心""宾客席"均为同一宴会厅的不同区域）必须合并到同一个场景文件中。场景拆分依据见《剧本处理规范》第 2.2.1 节。

### 2.1 入口索引文档

保存到 `project/{项目名}/全局依赖/场景设定/场景设定.md`

```markdown
# 场景设定

## 场景清单

| 场景 | 时代 | 基调 | 参考文档 |
|------|------|------|---------|
| {场景名1} | {时代1} | {基调1} | [具体设定/{场景名1}.md](具体设定/{场景名1}.md) |
| {场景名2} | {时代2} | {基调2} | [具体设定/{场景名2}.md](具体设定/{场景名2}.md) |
```

### 2.2 独立场景文档

每个场景一个独立文件，保存到 `project/{项目名}/全局依赖/场景设定/具体设定/{场景名}.md`

```markdown
# {场景名} — 场景设定

## 基本信息

| 字段 | 内容 |
|------|------|
| 场景名称 | {场景名称} |
| 所属时代 | {时代} |
| 出现剧集 | {剧集编号} |

## 氛围/基调

{氛围描述}

## 视觉描述

{场景的视觉元素描述}

## 关键元素

- {元素1}
- {元素2}

## 光线/色彩要求

{光线和色彩的具体要求}

## 参考来源

- 剧本原文引用：{从剧本中提取这些信息的原文引用}
- 网络参考资料：{如果通过联网搜索补充了历史地理/建筑信息，在此标注搜索关键词和来源}【有则写，无则省略此条】
```

## 4. 分集剧本格式

每集一个文件，保存到 `project/{项目名}/{剧集号}/剧本.md`（文件名固定为 `剧本.md`，与 coordinator 的 path mapping 及 storyboard-director 的读取路径对齐）。

保真提取格式：保留原始剧本的幕/场景结构，**不做镜头级分解**。

文件首行 H1 标题写作 `# EP{剧集号}_{标题}`，作为 frontmatter 保留剧集号与标题信息（如 `# EP01_海权复兴·大国归位`）。

```markdown
# EP{剧集号}_{标题}

## 剧集信息

| 字段 | 内容 |
|------|------|
| 集号 | {剧集号} |
| 标题 | {标题} |
| 核心主题 | {主题} |
| 情感基调 | {基调} |

---

## 第一幕：{幕标题}

### 场景：{场景名}（{时代}）

**画面**：{从剧本中保真提取的场景画面描述}

**台词**：
> **{角色名}**（{语气}）：{台词内容}
> **{角色名}**（{语气}）：{台词内容}

**音效/配乐**：{从剧本中提取的音效和配乐说明}

---

## 第二幕：{幕标题}

...
```

## 5. 全局设定格式

保存到 `project/{项目名}/全局依赖/全局设定.md`（单一文件）。

> **重要**：所有全局设定内容必须合并到这一个文件，用 markdown 章节组织。**不要**输出到 `全局依赖/全局设定/` 目录下的多个文件。Coordinator 已在项目初始化时创建占位文件，producer 直接覆盖写入。

```markdown
# 全局设定

## 世界观

{时代背景、地理环境、社会制度、文化氛围等世界设定。如涉及真实历史内容，融入联网检索到的时代背景信息}

## 时间线

{梳理剧本中的关键事件时间顺序，标注重要节点。可用列表或表格}

| 时间节点 | 事件 | 备注 |
|----------|------|------|
| {节点1} | {事件1} | {备注} |

## 人物关系

{归纳核心角色之间的关系：亲属、敌对、上下级、师徒等。可用文字描述或关系表}

| 角色 | 关系 | 对象 |
|------|------|------|
| {角色名} | {关系类型} | {对象角色名} |

## 风格基调

{整体视觉风格、色彩倾向、情绪基调。融合多模态分析的画风参考信息}

| 字段 | 内容 |
|------|------|
| 视觉风格 | {如：超写实影视级画面/3D卡通皮克斯风格/吉卜力风格等} |

## 参考来源

- 剧本原文引用：{从剧本中提取这些信息的原文引用}
- 网络参考资料：{如果通过联网搜索补充了历史背景信息，在此标注搜索关键词和来源}【有则写，无则省略此条】
```

## 6. Markdown 格式约束

1. **编码**：所有文件使用 UTF-8（无 BOM）编码
2. **换行**：使用 LF（Unix 风格）换行
3. **分隔**：幕与幕之间使用 `---` 分隔
4. **标题层级**：
   - 文件标题：`# {标题}`
   - 一级分节：`## {节标题}`
   - 二级分节：`### {子节标题}`
5. **表格**：使用标准 GFM（GitHub Flavored Markdown）表格格式
6. **台词引用**：使用 blockquote `>` 包裹台词内容
7. **文件名**：
   - 全局设定：`全局设定.md`（单一文件，路径 `全局依赖/全局设定.md`）
   - 角色设定索引：`角色设定.md`
   - 角色独立文档：`具体设定/{角色名}.md`，如 `具体设定/郑和.md`
   - 场景设定索引：`场景设定.md`
   - 场景独立文档：`具体设定/{场景名}.md`，如 `具体设定/明朝龙江关码头.md`
   - 道具设定索引：`道具设定.md`
   - 道具独立文档：`具体设定/{道具名}.md`，如 `具体设定/宝船模型.md`
   - 分集剧本：`剧本.md`（文件名固定，剧集号与标题通过首行 H1 `# EP{剧集号}_{标题}` 保留）
