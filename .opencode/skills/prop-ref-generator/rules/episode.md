# 剧集级参考流程

> 共享定义（Prompt 模板、参数表、校验规则）见 `rules/common.md`。

## 触发条件

- 阶段：剧集级参考图（episode_prop_ref / episode_scene_ref）
- 输入：分镜脚本 + 道具设定 + 全局基准资产

## 执行步骤

### 步骤 1：收集输入文件

| 文件 | 用途 |
|------|------|
| `project/{项目名}/{剧集号}/分镜/分镜脚本.json` | 提取该集道具使用信息 |
| `project/{项目名}/全局依赖/全局设定.md` | 画风参考 |
| `project/{项目名}/全局依赖/道具设定/道具设定.md` | 道具索引清单 |
| `project/{项目名}/全局依赖/道具设定/具体设定/{道具名}.md` | 各道具详细设定（含「出现场合」字段） |
| `project/{项目名}/全局依赖/道具设定/道具参考图/{道具名}_{出现场合}_基准.png` | 全局基准资产（文件名含出现场合标识） |
| `project/{项目名}/前期采样/道具/{道具名}*.png` | 道具采样图（可选，若存在则作为额外参考） |
| `project/{项目名}/前期采样/风格/*.png` | 风格参考图 |

### 步骤 2a：模式判断

对每个需要生成的道具，检查 `前期采样/道具/` 下是否存在以该道具名命名的图片文件：

> **定位全局基准资产**：读取 `具体设定/{道具名}.md` 的「基本信息」表，提取 `出现场合` 字段。全局基准资产文件名为 `{道具名}_{出现场合}_基准.png`（出现场合取首集集号或`全剧`）。**必须**使用该文件名定位全局基准资产，不得使用不含出现场合的旧格式文件名。

| 模式 | 条件 | string0（一致性引导词） | 参考图 |
|------|------|------------------------|--------|
| **模式 A** | `前期采样/道具/{道具名}*.png` 存在 | **写实风格**: `"道具形态、结构、材质与质感严格遵循参考图片1-图片n"`; **非写实风格**: `"道具形态与结构严格遵循参考图片1-图片n"` | 全局基准资产 + **道具采样图（放images[1]）** + 风格参考图 |
| **模式 B** | `前期采样/道具/{道具名}*.png` 不存在 | `"道具形态与材质质感严格参考图片1"` | 全局基准资产 + 风格参考图 |

> **模式 A 约束**：string0 必须使用"严格遵循"语气，images 数组须包含道具采样图和全局基准资产。采样图为原始形态基准，全局基准资产为已生成的统一风格基准，两者共同约束。若采样图与全局基准资产的形态/颜色存在差异，以采样图为准（采样图为更高优先级参考源）。

### 步骤 2：提取剧集道具清单

分析分镜脚本，汇总该集不重复的道具名。每个道具 1 个 task（上4下2六视图）。

#### 判断标准：何时需要生成剧集级道具参考

| 条件 | 说明 |
|------|------|
| 特殊状态变化 | 如"罗盘指针失灵"、"平板显示特定画面" |
| 剧情关键道具 | 需要精确视觉定位 |
| 外观与全局有差异 | 破损/改装/特殊光照 |

### 步骤 2b：提取视觉风格

在执行步骤 3 构建 prompt 之前，按 `rules/common.md` 中「视觉风格提取」章节的规则，从 `project/{项目名}/全局依赖/全局设定.md` 中提取视觉风格关键字，记为 `{style_desc}`。

> **无全局设定时**：从 `前期采样/风格/` 中的参考图文件名判断风格倾向，仍无法判断时使用默认值"超写实影视级画面"。

### 步骤 3：构建 Prompt

- **string0**：按步骤 2a 模式判断确定。**模式 A 根据风格类型选择：写实风格使用 `"道具形态、结构、材质与质感严格遵循参考图片1-图片n"`，非写实风格使用 `"道具形态与结构严格遵循参考图片1-图片n"`。模式 B 使用 `"道具形态与材质质感严格参考图片1"`**

| 参数 | 提取说明（模式 B，无采样图） | 模式 A（有采样图）的参考图优先约束 |
|------|---------|----------------------------------|
| style_desc | 从全局设定提取的视觉风格描述，如"超写实影视级画面"。无全局设定时默认"超写实影视级画面" | 同通用 |
| string1 | 道具 + 本集状态标识，如"明代航海罗盘——风暴失灵状态" | 同通用 |
| string2 | 固定值 `"道具特写、戏剧性光照、材质细节突出"` | 同通用 |
| string3 | 正面（剧集版），≥50字，基于全局正面 + 本集状态变化 | **零文字描述**。仅写 `正面` |
| string4 | 背面（剧集版），≥50字，基于全局背面 + 本集变化 | **零文字描述**。仅写 `背面` |
| string5 | 侧面（剧集版），≥50字，基于全局侧面 + 本集磨损/损坏 | **零文字描述**。仅写 `侧面` |
| string6 | 顶部（剧集版），≥50字，基于全局顶部 + 本集变化 | **零文字描述**。仅写 `顶部` |
| string7 | 关键特写1（剧集版），≥50字，本集需突出的最重要局部细节 | **零文字描述**。仅写 `{部位名}` |
| string8 | 关键特写2（剧集版），≥50字，另一角度的本集细节 | 同 string7 |
| string9 | 本集光线与氛围，≥50字，从本集场景推断 | **零文字描述**。仅写 `光线与氛围严格遵循参考图` |
| string10 | 本集状态 + 环境，≥40字 | 仅写 `道具状态与品相严格遵循参考图所示` |
| string11 | 与 style_desc 风格一致的质感描述，如"剧集级道具概念图质感" | 同通用 |

### 步骤 4：生成任务 JSON

```json
{
  "model": "gpt-image-2",
  "tasks": [
    {
      "prompt": "道具形态、结构、材质与质感严格遵循参考图片1-图片n，{style_desc}，{string1}，1K分辨率，极致细节，{string2}，上4下2六视图排版。\n上方画面：左起依次为……\n下方画面：左起依次为……",
      "imageSize": "1K",
      "aspectRatio": "16:9",
      "filename": "{道具名}_{剧集号}集.png",
      "images": [
        "project/{项目名}/全局依赖/道具设定/道具参考图/{道具名}_{出现场合}_基准.png",
        "project/{项目名}/前期采样/道具/{道具名}.png",
        "project/{项目名}/前期采样/风格/{风格文件}.png"
      ]
    }
  ],
  "output_path": "project/{项目名}/{剧集号}/道具参考图/"
}
```

**自检清单：**
- □ 只有检测到变化的道具才生成 task
- □ 已从 `具体设定/{道具名}.md` 提取 `出现场合` 字段，images[0] 使用 `{道具名}_{出现场合}_基准.png` 定位全局基准资产
- □ prompt 包含"上4下2六视图排版"
- □ style_desc 已从全局设定中提取并注入 prompt，非硬编码风格
- □ 模式 A：images 包含全局基准资产（images[0]）+ 道具采样图（images[1]）+ 风格参考图（images[2]），string0 使用"严格遵循"
- □ 模式 A string0 根据风格类型正确选择：写实用"形态、结构、材质与质感"，非写实用"形态与结构"
- □ 模式 B：images 包含全局基准资产（images[0]）+ 风格参考图（images[1]）
- □ **模式 A 的方位视图描述（string3~string8）零描述——仅视角名称（正面/背面/侧面/顶部/部位名），不映射图片编号**

### 步骤 5：Schema 校验
1. `validate_top_level(data)` 校验顶层
2. `validate_tasks(tasks, "episode")` 校验任务列表

### 步骤 6：输出完成提示

## 参考图上传顺序

### 模式 A（有道具采样图）

| 位置 | 内容 |
|------|------|
| images[0] | 全局基准资产（`{道具名}_{出现场合}_基准.png`） |
| images[1] | 道具采样图（`前期采样/道具/{道具名}*.png`） |
| images[2] | 风格参考图（`前期采样/风格/*.png`） |

### 模式 B（无道具采样图）

| 位置 | 内容 |
|------|------|
| images[0] | 全局基准资产（`{道具名}_{出现场合}_基准.png`） |
| images[1] | 风格参考图（`前期采样/风格/*.png`） |

## 差异对比

| 维度 | 全局基础参考 | 剧集级参考 |
|------|-------------|-----------|
| 触发阶段 | 全局视觉资产生成（global_character_tasks ~ global_scene_art） | 剧集级参考图（episode_prop_ref / episode_scene_ref） |
| 核心输入 | 道具设定 + 风格采样 | 分镜脚本 + 基准资产 |
| 排版 | 上4下2六视图 | 上4下2六视图 + 本集差异 |
| 输出路径 | `全局依赖/` | `{剧集号}/` |
