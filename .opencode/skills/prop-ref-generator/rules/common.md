# 共享定义

两个定位模式（global / episode）共用以下规范。差异点在各自主文件中说明。

## 参考图严格遵循原则（所有模式通用）

当 `前期采样/道具/{道具名}*.png` 参考图存在时，Agent **必须**严格遵守以下规则：

### 参考图的权威地位

| 层级 | 优先级 | 说明 |
|------|--------|------|
| **P0 — 强制遵守** | 最高 | 道具的形态、结构、材质、颜色、纹理、比例，必须以采样图为**唯一基准**，不得偏离或自由发挥 |
| **P1 — 尽量跟随** | 高 | 采样的光影风格、构图方式、质感倾向，必须在 prompt 中显式声明"严格遵循参考图" |
| **P2 — 允许补充** | 中 | 参考图未覆盖的视角（背面、顶部、特写）可以基于正面图合理推断并明确声明推断依据 |
| **P3 — 可补充细节** | 低 | 仅参考图完全无法提供的视觉信息（如特定使用场景中的环境交代），可额外补充 |

### 参考图对 Prompt 各位置的约束

参考图直接约束 prompt 的以下维度的描述：

| prompt 位置 | 约束来源 | 约束规则 |
|-------------|---------|---------|
| string0（一致性引导词） | 道具采样图（排除风格参考图） | 声明"严格遵循参考图"语气。n=1 时用 `"道具形态、结构、材质与质感严格遵循参考图片1"`；n≥2 时用 `"道具形态、结构、材质与质感严格遵循参考图片1-图片{n}"`。`n` = 道具采样图数量（**不含**末尾的风格参考图） |
| string12（风格参考声明） | 风格参考图 | **必须**显式声明风格参考图的作用，告知模型末尾图片用于引导视觉风格而非约束道具形态 |
| string3~string6（方位视图） | 正面采样图为主 | 正面/背面/侧面/顶部的色彩、材质、结构描述必须与参考图一致 |
| string7~string8（特写） | 全局采样图 | 材质细节、工艺纹样的描述须与参考图匹配 |
| string9（光线与氛围） | 参考图的光影 | 从参考图中提取实际的光线方向、色温、对比度，融入描述 |
| images[] | 所有参考图 | **必须**列出所有可用的参考图路径 |

### 参考图分析步骤

在构建 prompt 之前，**必须**先执行以下分析：

```
1. 列出所有匹配的采样图文件（文件名、路径）
2. 根据文件名推断视觉内容（如"喜被-造型1.jpg" → 喜被的整体造型图）
3. 确认参考图覆盖了多少个视角/维度
4. 对未被覆盖的维度（如背面、顶部），在 prompt 中基于正面视角合理推断
5. 将参考图路径填入 images 数组，采样图在前，风格图在后
```

### 风格类型自适应规则

根据从 全局设定.md 提取的 style_desc 判断视觉风格类型：

| 风格类型 | 判断依据（style_desc 包含以下关键字） | 参考图遵循策略 |
|---------|-----------------------------------|--------------|
| 写实风格 | 写实、真实、影视级、照片级、超清、8K、写实摄影、电影级 | 严格遵循参考图的**形态、结构、材质、质感**所有维度 |
| 非写实风格 | Q版、Chibi、卡通、乙烯基玩具、哑光塑料、可爱、3D渲染、手绘、赛璐璐、水墨 | 仅参考**形态与结构**（造型），材质与质感遵从 style_desc |

**判断逻辑**：检查 style_desc 中是否包含以上关键字。不含任何关键字时默认写实风格。

### 模式 A Prompt 构建原则（有道具采样图）

当存在前期采样参考图时，Prompt 的构建逻辑必须与模式 B 相反：

| 维度 | 模式 B（无采样图，不可违反） | 模式 A（有采样图，不可违反） |
|------|---------------------------|---------------------------|
| 描述来源 | 从设定文件提取详细文字描述 | **完全不写产品细节描述**——全部交由参考图引导 |
| 方位视图（string3~string8） | 完整的设定描述，≥50字 | **零文字描述**。仅声明视角名称（正面/背面/侧面/顶部/部位名），不写任何材质、颜色、形态的文字，不映射具体图片编号 |
| 光线氛围（string9） | 从使用场景推断 | **零文字描述**。仅声明"光线与氛围严格遵循参考图" |
| 描述长度 | 用完整文字补充视觉信息 | **零描述**——参考图能传达的信息，文字一个字都不写 |
| 核心目标 | 用文字引导模型生成 | **完全依赖参考图引导**，文字只起"指向"作用，不承担"描述"作用 |

**模式 A 错误示例（从设定照搬，文字堆砌）：**
```
上方画面：左起依次为正面完整展示思辰红色礼品盒，正红色中国红盒面色彩饱满浓郁，表面印有世辰品牌标识及龙凤纹样，盒体方正比例端庄，高档烤漆质感表面反光均匀强烈，视觉冲击力强...
```
→ 问题：这些信息完全由参考图提供，文字只是重复，反而稀释了参考图的权威性。

**模式 A 正确示例（纯参考图引导，零文字描述）：**
```
上方画面：左起依次为正面、背面、侧面、顶部。
下方画面：左起依次为烫金纹样细节、盒角工艺特写。
光线与氛围严格遵循参考图，
道具状态与品相严格遵循参考图所示。
```
→ 原则：所有产品细节信息（材质、颜色、形态、纹样）**一个字不写**，完全依赖参考图引导。string0 中的 `"严格遵循参考图片1-图片n"` 是唯一的产品细节来源。视角名称仅标注方位，不映射具体图片编号。

> **非写实风格下**：string0 改为 `"道具形态与结构严格遵循参考图片1-图片n"`，材质质感信息完全不写入方位视图描述，由 style_desc 统一控制。

## 道具上4下2六视图硬约束

- 一个道具 = 一个 task。每个道具只生成 1 个 task，该 task 的 prompt 生成 **一张上4下2六视图排版图**，包含 6 个画面。
- **aspectRatio 必须固定为 16:9**（横向容纳六视图排版）。

### 六视图布局定义

| 行 | 数量 | 内容 | 说明 |
|----|------|------|------|
| 上方 | 4 个 | 正面、背面、侧面、顶部 | 四方向完整展现道具几何形态与结构全貌 |
| 下方 | 2 个 | 关键部位特写1、关键部位特写2 | 两个关键部位的局部细节放大 |

### 六视图视角说明

| 位置 | 视角 | 说明 |
|------|------|------|
| 上方左1 | 正面 | 正面视角 Front View | 道具正面的完整展示，体现主体造型与比例 |
| 上方左背 | 背面视角 Back View | 道具背面展示，呈现背面结构与特征 |
| 上方右背 | 侧面视角 Side View | 道具侧面展示，体现厚度/深度与轮廓 |
| 上方右顶 | 顶部视角 Top View | 从上向下垂直俯视，展示顶部结构与平面布局 |
| 下方左 | 关键部位特写1 Key Detail 1 | 最重要或最复杂的局部细节放大 |
| 下方右 | 关键部位特写2 Key Detail 2 | 次重要或另一角度的局部细节放大 |

## 单道具图文对应

全局依赖的 `道具设定/具体设定/` 下每个 `.md` 文件代表一个独立道具。全局基础参考阶段需要为每个道具生成 1 张道具参考图，因此 task 数量 = 具体设定中的道具数量。

| 道具设定文件 | 对应的 task 数 |
|-------------|--------|
| 每个 `.md` 文件 | 1 个 task |

## 缺省值原则（重要）

AI 图像模型对物件属性有统计偏见——必须显式声明材质、颜色、年代感、尺寸、光源。

| 属性 | 风险 | 正确做法 |
|------|------|---------|
| 材质/质感 | 金属默认铜锈/做旧 | 描述具体材质（铜质/木质/雕花/塑料） |
| 颜色 | 默认与设定不符 | 声明主色/辅色/装饰色/纹样色 |
| 年代感 | 古代默认斑驳褪色 | 描述"全新/做旧/古旧" |
| 尺寸感 | 比例扭曲 | 描述实际大小及与人手的比例参照 |
| 展示环境 | 默认影棚 | 描述道具在使用场景中的光线环境 |

## 视觉风格提取

构建 prompt 前，从全局设定中提取视觉风格描述：

1. 读取 `project/{项目名}/全局依赖/全局设定.md`
2. 提取**视觉风格关键字**：如"Q版3D渲染风格，乙烯基玩具质感"、"超写实影视级写实"、"手绘赛璐璐卡通"、"3D渲染皮克斯风格"、"水墨淡彩"等
3. 将提取到的风格描述记为 `{style_desc}`，用于 prompt 模板中

> **无全局设定时**：退而求其次从 `前期采样/风格/` 中的参考图文件名判断风格倾向。仍无法判断时使用"超写实影视级画面"作为默认风格描述。

## Prompt 模板

Prompt 必须严格使用下方模板，逐字替换占位符（string0~string12）。**禁止**拆分为 6 个独立 task。

```
{string0}，
{style_desc}，{string1}，1K分辨率，极致细节，{string2}，上4下2六视图排版。
上方画面：左起依次为{string3}、{string4}、{string5}、{string6}。
下方画面：左起依次为{string7}、{string8}。
{string9}，
{string10}，
{string11}.
{string12}
```

## 参数说明

| 参数 | 含义 | 通用说明（模式 B，无采样图） | 模式 A 附加约束（有采样参考图） |
|------|------|---------|---------------------------|
| style_desc | 视觉风格 | 从全局设定提取的风格描述，如"Q版3D渲染风格，乙烯基玩具质感"、"超写实影视级画面"。无全局设定时取默认值"超写实影视级画面" | 同通用 |
| string0 | 一致性引导词 | 用文字声明"严格遵循设定描述" | **写实风格必须使用** `"道具形态、结构、材质与质感严格遵循参考图片1-图片n"`，不可弱化措辞。**非写实风格必须使用** `"道具形态与结构严格遵循参考图片1-图片n"`（去掉"材质与质感"，因为材质质感由 style_desc 决定）。**注意单复数**：n=1 时写 `"参考图片1"`（不要写成"图片1-图片1"），n≥2 时写 `"参考图片1-图片{n}"`。`n` = 道具采样图数量（**不含**末尾的风格参考图）。这是**唯一**的产品细节来源 |
| string1 | 道具类型/风格标识 | 如"明代航海器具特写" | 同通用 |
| string2 | 镜头语言 | 如"焦点精准、材质质感突出" | 同通用 |
| string3 | 正面视角 | ≥50字，从设定提取完整文字描述 | **零文字描述**。仅写 `正面` |
| string4 | 背面视角 | ≥50字，从设定提取完整文字描述 | **零文字描述**。仅写 `背面` |
| string5 | 侧面视角 | ≥50字，从设定提取完整文字描述 | **零文字描述**。仅写 `侧面` |
| string6 | 顶部视角 | ≥50字，从设定提取完整文字描述 | **零文字描述**。仅写 `顶部` |
| string7 | 关键部位特写1 | ≥50字，从设定提取完整文字描述 | **零文字描述**。仅写 `{部位名}`，如"龙凤纹样细节" |
| string8 | 关键部位特写2 | ≥50字，从设定提取完整文字描述 | 同 string7：`{部位名}` |
| string9 | 光线与氛围 | ≥50字，从使用场景推断 | **零文字描述**。仅写 `光线与氛围严格遵循参考图` |
| string10 | 道具状态 + 环境关联 | ≥40字 | 仅写 `道具状态与品相严格遵循参考图所示` |
| string11 | 整体质感 | 与 style_desc 风格一致的质感描述，如"电影级道具概念图质感，静物摄影风格" | 同通用 |
| string12 | 风格参考声明 | 留空（模式B的string0已覆盖风格参考） | **必须**写入，格式：`"图片{n+1}为视觉风格参考，用于引导整体色调、光影氛围与画面质感，不约束道具形态与结构。"`，其中 n = 道具采样图数量 |

## Schema 校验

调用 `scripts/validators.py` 的 `validate_tasks(tasks, mode)` 和 `validate_top_level(data)`。

**顶层固定值（不可变）：**
- `model` **必须固定为** `"gpt-image-2"`
- `imageSize` **必须固定为** `"1K"`
- `aspectRatio` **必须固定为** `"16:9"`

**校验项：**
- 基础字段：prompt, imageSize, aspectRatio, filename, images
- 类型检查：imageSize **必须固定为** `1K`，aspectRatio **必须固定为** `16:9`
- prompt 完整性：无占位符 (string0~string12)，必须包含"六视图"或"上4下2"字样，长度 ≥ 50
- string12 检查（模式 A）：必须包含"视觉风格参考"字样
- filename：.png 结尾

校验通过标准：两个函数均返回空列表。
