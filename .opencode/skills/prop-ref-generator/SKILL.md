# 道具参考生成 Skill

生成道具参考图任务 JSON，由 Art-director 执行生图。

**设计原则**：所有智能决策由你（Agent）完成——读取文件、理解设定、构建 Prompt、组装任务表。Python 脚本仅做无状态的 Schema 校验。

## 路径约定

所有项目文件位于 `project/{项目名}/` 下：

```
project/{项目名}/
├── 全局依赖/
│   ├── 角色设定/角色设定.md
│   ├── 场景设定/场景设定.md
│   ├── 道具设定/道具设定.md              ← 入口索引
│   ├── 道具设定/具体设定/{道具名}.md      ← 独立道具文件（含「出现场合」字段）
│   ├── 道具设定/道具参考图/{道具名}_{出现场合}_基准.png ← 全局基准资产（产出物）
│   ├── 角色设定/角色设定.md
│   ├── 角色设定/角色参考图/{角色名}_基准.png
│   └── 场景设定/场景参考图/
├── 前期采样/
│   ├── 道具/{道具名}*.png               ← 道具采样图（可选，若有则严格遵循）
│   └── 风格/*.png                       ← 风格参考图
├── 原始剧本.md
└── {剧集号}/
    ├── 剧本.md
    ├── 分镜/分镜脚本.json
    └── 道具参考图/                  ← 剧集级道具参考图（产出物）
```

### 出现场合字段

道具定义文件（`具体设定/{道具名}.md`）的「基本信息」表中**必须**包含 `出现场合` 字段，标注该道具在剧中的出场信息：

| 出现场合值 | 含义 | 文件名示例 |
|-----------|------|-----------|
| `全剧` | 贯穿全剧的通用道具 | `{道具名}_全剧_基准.png` |
| `EP01` | 首次出场于 EP01 | `{道具名}_EP01_基准.png` |
| `EP01,EP13` | 多集出场，列出所有集号 | `{道具名}_EP01_基准.png`（取首集） |

> **出现场合用于文件名时取首次出场集号**（多集出场取第一集）。`全剧` 类型保持原样。此字段防止监制批量创建道具后，道具师产出的资产被错误引用到不该出场的剧集中。

## 输出 Schema

产出 `道具参考图_任务表.json` 必须符合 `.opencode/schemas/image-generation.json` 定义。核心字段：

| 字段 | 类型 | 固定值 | 说明 |
|------|------|--------|------|
| `prompt` | string | — | 生图提示词（必填） |
| `model` | string | `"gpt-image-2"` | 固定为 gpt-image-2，不可变 |
| `imageSize` | string | `"1K"` | 固定为 1K，不可变 |
| `aspectRatio` | string | `"16:9"` | 固定为 16:9，不可变 |
| `filename` | string | — | 输出文件名，以 .png 结尾 |
| `images` | string[] | — | 参考图路径列表 |

## 双定位模式

| 模式 | 触发阶段 | 核心输入 | 视图数 | 输出路径 |
|------|---------|---------|--------|---------|
| 全局基础参考 | 全局视觉资产生成（global_character_tasks ~ global_scene_art） | 道具设定 + 风格采样 | 上4下2六视图 | `全局依赖/道具设定/道具参考图/道具参考图_任务表.json` |
| 剧集级参考 | 剧集级参考图（episode_prop_ref / episode_scene_ref） | 分镜脚本 + 道具设定 + 全局基准资产 | 上4下2六视图 | `{剧集号}/道具参考图/道具参考图_任务表.json` |

## 入口

- 共享定义（Prompt 模板、参数表、校验规则）：`rules/common.md`
- 全局级道具参考生成规则：`rules/global.md`
- 剧集级道具参考生成规则：`rules/episode.md`
