# Seedance 2.0 公式详解

## 一、基础公式（按任务类型）

Seedance 2.0 原生支持音频与视频联合生成，可同时参考视频、图片、音频等全模态素材，精准锁定人物样貌、动作特效、视觉风格、配音音色。

### 1. 全模态参考

从素材中提取部分元素（主体、风格、场景、音效），生成全新视频。

**适用场景**：动作迁移、主体复用、氛围借鉴

**推荐句式**：
- 图片参考：`参考<图片N>中的<主体N>，生成...`
- 视频参考：`参考<视频N>中的<动作/运镜/风格/音效>，生成...`
- 音频参考：`参考<音频N>中的音色，生成...`

### 2. 编辑视频

在原视频基础上局部或全局修改。**未提及的部分默认保持不变**。

**适用场景**：局部替换、主体抹除、属性修改

**推荐句式**：
- 增加元素：清晰描述 `<元素特征> + <出现时机> + <出现位置>`
- 修改元素：`严格编辑<视频N>，将其中的<原特征>修改为<新特征>`
- 删除元素：点明需删除的元素；对保持不变的元素在提示词中加以强调，表现更佳

### 3. 延长视频

在时间维度延续原视频，要求音视频风格、主体与叙事保持一致。模型自动截取衔接部分合成，输入视频原有片段不会重复生成。

**适用场景**：续写剧情、延展动作、补全片段

**推荐句式**：
- 延长：`向前/向后延长<视频N>，生成...`
- 轨道补全：`<视频1> + <过渡画面描述> + 接 <视频2> + <过渡画面描述> + 接 <视频3>`
  - 最多支持 3 段视频输入，总时长不得超过 15 秒
  - 生成时自动截取首尾视频的衔接部分，仅保留必要片段参与合成

> **警告**：编辑/延长任务直接使用 `<视频N>` 指代视频，禁止使用"参考<视频N>"，以免被误判为参考任务。

### 4. 组合任务

**适用场景**：参考某个素材，编辑另一个素材。

**推荐句式**：`参考<图片/视频N>的[参考维度]，严格编辑<视频X>，[具体编辑内容]`

## 二、进阶公式（八要素）

Seedance 2.0 本质是全模态 AI 导演：同时读取文字提示词、图片、视频、音频，内部拆成"空间层"（画面里有什么）和"时间层"（事情如何随时间变化）两个维度。

好提示词 = 工程型指令，不是文案型形容：

```
提示词进阶公式：精准主体 + 动作细节 + 场景环境 + 光影色调 + 镜头运镜 + 视觉风格 + 画质 + 约束条件
```

编写顺序：先锁定"谁"在"干什么"，再交代"在哪"、"什么氛围"，然后告诉模型"怎么拍"，最后用风格、画质和约束条件收紧结果。

### 要素 1：定义主体

主体可以是人物、道具、场景等。

- **推荐句式**：`将<图片/视频N>中的[主体核心特征]定义为<主体N>`
- **核心特征要求**：2–3 个清晰、稳定的静态特征（服饰、发型、外观、类别），确保唯一可识别
- **示例**：
  - `将图片1中穿红色连衣裙、戴草帽的女人定义为主体1`
  - `将图片1中穿红色连衣裙、戴草帽的女人定义为张红`（支持命名）
- **指代规则**：
  - 未定义主体的简单场景：每次提到主体用 `<主体N>@<图片N>`，如 `张三@图片1`
  - 已定义主体：全程使用同一标签。示例：`将视频1中的高个子男人定义为警察，将另一个矮个子男人定义为小偷`，后续持续用"警察"/"小偷"指代
  - 使用素材库（Asset ID）时仍需用 `<图片/视频N>` 指代主体——模型无法直接关联 Asset ID 与参考内容
- 描述简洁，避免冗余与语义冲突（同一主体不得出现矛盾特征）
- 空间关系优先通过参考图表达

### 要素 2：分镜时序

把视频拆成几个分镜，按事件发生顺序动态描述每个分镜：**谁 + 在哪 + 做什么 + 镜头怎么动**。

反面案例：`男人在街头紧张地奔跑，画面很有电影感。`

正面案例：
```
镜头 1：街巷侧拍，男人缓慢起跑，带有急促的呼吸感。
镜头 2：男人撞翻水果摊，镜头快速摇动并给到男人惊恐的特写。
镜头 3：男人翻过矮墙消失，镜头缓慢拉远定格在空荡的街道。
```

规则：
- 使用"镜头1/镜头2/镜头3"标识，按事件发生顺序（先主后次）
- 不强制限制每段时长——模型对精确时间（如 0–3 秒）支持不稳定，强行限制可能导致异常
- 每个镜头推荐组织逻辑：运镜/镜头切换方式 → 主体动作与表情 → 位置或空间变化 → 音频信息

### 要素 3：运镜写法

直接使用标准运镜术语：中景、特写、全景、缓慢推镜、平稳横移、固定镜头等。

> **注意**：一个镜头里只指定 1 种运镜方式，同时要求推拉摇移会增加画面不稳定性。

### 要素 4：画质、风格与约束词

**画质**（定义清晰度、细节纹理、光影质感）：
- 示例：`高清，细节丰富，电影质感，色彩自然，光影柔和`

**风格**（设定美术画风与视觉调性）：
- 示例：`赛博朋克冷蓝紫色调`、`复古胶片`、`日系清新`
- 参考图风格与目标风格不一致时，必须显式强调风格词，否则易漂移为写实风格

**约束词**（规避瑕疵、畸形、不合理元素，保障稳定合规）：

| 目标 | 约束词模板 |
|------|-----------|
| 避免字幕 | `保持无字幕`、`避免生成任何文字或字幕` |
| 避免 Logo | `不要生成Logo` |
| 避免水印 | `不要生成水印` |
| 避免双胞胎 | `视频全程禁止出现外形、着装、配饰完全一致的人物，禁止生成同款分身、双胞胎效果，同一画面中仅保留单个对应人物，不出现人物重复复刻` |
