# 符号规范、文字生成与音频描述

## 一、特殊字符规范

提示词中合理使用符号帮助模型准确理解信息类型：

| 信息类型 | 符号 | 示例 |
|---------|------|------|
| 音乐 | （） | （背景中播放着快节奏的摇滚乐） |
| 音效 | <> | <远处传来狗叫声> |
| 台词 | {} | {你好，世界} |
| 字幕 | 【】 | 【第一章：启程】 |

- 台词为小语种（非中英文）时需标注语种：`用日语说道{こんにちは}`
- 台词语言需统一，避免中英文混用（专有名词除外）

## 二、文字生成

模型支持生成常用文字，能根据情境自动匹配合适风格与颜色，也支持指定文字的颜色、风格、出现方式、时机、位置。

**编写原则**：优先使用常用字，避免生僻字与特殊符号。

### 广告语（Slogan）

模板：
```
「文字内容」+「出现时机」+「出现位置」+「出现方式」，「文字特征（颜色、风格）」
```

案例：
```
手绘漫画风格，三个人围坐在一起吃图片1中的炸鸡，气氛友好愉悦，后画面逐渐模糊，画面中部显示文字"快乐尽在 Seedance"。
```

### 字幕

模板：
```
画面底部出现字幕，字幕内容为"……"，字幕需与音频节奏完全同步。
```

案例：
```
图片中的两人在办公室聊天，女性先说话，她说道："你每次卡点到，是不是很享受这种刚刚好的感觉？"男性笑着回应："我有我的节奏"。角色说话时，对话随意自然，画面底部出现对应台词字幕。
```

### 气泡台词

模板：
```
「角色」说："……"，角色说话时周围出现气泡，气泡里写着台词。
```

案例：
```
图片1中的两人穿着运动服在学校的操场跑步，女孩看向男孩，自信地笑着说："We can definitely do it!"镜头切到男孩的近景，他犹豫地回答："Are you sure?"镜头切回女孩的中近景，她语气轻快地说："Yes!"情绪明亮而坚定。说话的角色周边出现气泡，气泡里是对应台词。
```

## 三、音频与音色

### 音色参考不准的对策

- 在提示词中补充细致的音色特征描述，例如：`使用@音频1低厚温润带细碎颗粒感中年男声的音色说`
- 保持视频台词风格与参考音频的语气、表述风格相近，提升音色还原度与稳定性

### 中文发音不准的对策

模型对多音字、生僻字、形近字容易读错。将易读错文字替换为**发音一致的常用同音字**。

- 示例：`螭龙山` → 改写为 `吃龙山`
- 该方案仅为优化手段，无法完全规避所有发音问题

### 视频结尾噪音

旁白视频片尾易出现突兀咔哒声、截断杂音。对策：重新生成，或在剪辑工具中对片尾音轨做音量包络线淡出处理。
