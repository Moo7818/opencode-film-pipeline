# Seedance 2.0 提示词优化器

将用户的视频创意转化为 Seedance 2.0 的"工程型指令"：谁、在什么场景、做什么动作、镜头如何运动、按怎样的时间顺序发生——分别投递给模型的空间层与时间层。

## 核心工作流

按以下五步处理每个提示词优化请求：

### 1. 识别任务类型

先判定任务类型，选择对应基础公式。若用户未说明，主动询问素材情况（有无参考图/视频/音频）。

| 任务类型 | 判定特征 | 基础句式 |
|---------|---------|---------|
| 全模态参考 | 从素材提取元素生成全新视频 | `参考<图片/视频/音频N>中的<主体/动作/运镜/风格/音色>，生成...` |
| 编辑视频 | 在原视频上增删改元素 | `严格编辑<视频N>，将其中的<原特征>修改为<新特征>` |
| 延长视频 | 时间维度延续原视频 | `向前/向后延长<视频N>，生成...` |
| 轨道补齐 | 多段视频间生成过渡 | `<视频1> + <过渡画面描述> + 接 <视频2>` |
| 组合任务 | 参考一素材编辑另一素材 | `参考<图片/视频N>的[维度]，严格编辑<视频X>，[编辑内容]` |

**关键区分**：编辑/延长任务直接用 `<视频N>` 指代，禁止写"参考<视频N>"，否则被误判为参考任务。

### 2. 定义主体

- 用 2–3 个清晰稳定的静态特征（服饰、发型、外观、类别）定义主体，确保唯一可识别：`将<图片N>中[核心特征]的[对象]定义为<主体N>`
- 已定义主体后，全程使用同一标签指代，避免省略或矛盾特征
- 未定义主体的简单场景，用 `<主体>@<图片N>` 绑定素材（如：张三@图片1）
- 使用素材库 Asset ID 时，仍需用 `<图片/视频N>` 指代，不得以 Asset ID 替代
- 空间关系优先通过参考图表达，减少复杂文字描述

### 3. 构建分镜时序

复杂叙事必须拆为时间轴化分镜，按事件发生顺序组织：

```
镜头 1：[运镜/机位] + [主体动作与表情] + [位置/空间变化] + [音频]
镜头 2：...
镜头 3：...
```

- 使用"镜头1/镜头2/镜头3"标识，先主后次
- 不强行限制每段精确时长（如"0–3秒"），让模型自然生成节奏
- 每个镜头只指定 1 种运镜方式，禁止同时推拉摇移

### 4. 套用进阶公式补全要素

```
精准主体 + 动作细节 + 场景环境 + 光影色调 + 镜头运镜 + 视觉风格 + 画质 + 约束条件
```

- **动作细节**：具体到手/腿/头/肩背，量化幅度、速度、力度；优先低缓连续小动作；写明动作过渡衔接；情绪必须外化为身体细节（详见 `references/action-emotion.md`）
- **运镜**：直接使用标准术语（中景、特写、全景、缓慢推镜、平稳横移、固定镜头）
- **画质**：高清、细节丰富、电影质感、色彩自然、光影柔和
- **风格**：明确美术调性（如"2D日漫风格"、"3D国漫CG"），参考图风格与目标不一致时必须强调
- **约束词**（默认附加）：`保持无字幕，避免生成任何文字或字幕，不要生成Logo，不要生成水印`

### 5. 自检清单

输出前逐项核对：

- [ ] 任务类型句式正确（编辑/延长未误用"参考"）
- [ ] 每个主体唯一定义且全程标签一致
- [ ] 复杂叙事已分镜，按时间顺序排列
- [ ] 每镜头至多 1 种运镜
- [ ] 情绪已外化为具体身体细节，无"很悲伤"类抽象词
- [ ] 无狂奔、大跳、剧烈翻滚等高爆发动作（除非用户明确要求）
- [ ] 台词语言统一，无中英文混用（专有名词除外）
- [ ] 符号规范：音乐`（）`、音效`<>`、台词`{}`、字幕`【】`
- [ ] 已附加画质词、风格词、约束词
- [ ] 台词用常用字，无生僻字/特殊符号/易错多音字
- [ ] 提示词精简聚焦，未直接粘贴完整剧本

## 与 libtv 管线衔接（本系统专用）

本 skill 负责**创作层语义**（提示词内容质量），不负责传输层格式。当优化结果需经 `video-director-libtv` 技能投递到 libtv 画布（Seedance 2.0 VIP 等模型）时，遵守以下衔接规则：

1. **最终拼装以 video-director-libtv 的 Prompt 格式硬约束为准**：引用行（`{名称}{类型}参考{{Image N}}`）+ 约束行（`画面严禁出现任何字幕，无配乐`）+ `---` 分隔线 + 分镜组文件内容。本 skill 产出的分镜与要素描述融入分镜组内容部分。
2. **素材指代语法转换**：本 skill 使用 Seedance 原生语法 `<图片N>/<视频N>/<音频N>`；进入 libtv 管线时须转换为 `{{Image N}}` / `{{Audio N}}`（N 与上传节点的排列序号一致）。
3. **约束词对齐**：本 skill 默认约束词（无字幕/无 Logo/无水印）与 libtv 固定约束行方向一致，两者并存不冲突；libtv 约束行不可省略。
4. **⛔ 管线内禁用配乐与字幕生成语法**：libtv 固定约束行为"画面严禁出现任何字幕，无配乐"。凡经本管线投递的内容，禁止使用音乐符号 `（）` 添加配乐描述，禁止使用字幕 `【】` 生成语法。音效 `<>` 与台词 `{}` 仅在 `enable_sound=true` 时保留。
5. **双模式切换**：由 `meta_query(scope=config)` 返回的 `config.video_prompt_mode` 控制。`optimized`（默认）= 本 skill 将组文件适配为 Seedance 工程型指令提示词（见下方「分镜脚本适配模式」）；`raw` = 原样拷贝组文件内容，不经过适配（旧行为）。
6. **prompt 传递方式**：经 libtv 投递时必须写临时 Python 脚本（放 `temp/`）经 subprocess 调用，禁止内联 CLI 参数。

## 分镜脚本适配模式（管线默认流程）

当 `meta_query(scope=config)` 返回的 `config.video_prompt_mode` 为 `optimized`（默认）时，video-director 读取分镜组文件后，按本节流程将其适配为 Seedance 工程型指令提示词，再交由 video-director-libtv 拼装投递。适配**内联完成**，不落盘中间文件。

### 适配目标

分镜脚本是面向制作的规划文档（17 字段结构 / 讲戏式叙事），Seedance 需要的是"工程型指令"（主体+动作+场景+运镜+风格+画质+约束的镜头时序叙事）。适配层负责这层格式转换，**不是重新创作**，而是**无损重组**。

### 字段映射表（详细 JSON → Seedance 要素）

| 分镜字段 | → Seedance 要素 | 适配规则 |
|---------|----------------|---------|
| `通用设定.风格质感` | 视觉风格 + 画质 | 提取风格关键词，置于提示词末尾全局收尾段 |
| `通用设定.场景名称` | 场景环境 | 置于首镜头场景建立段 |
| `通用设定.光线基调` | 光影色调 | 融入场景描述 |
| `通用设定.色调调性` | 光影色调 | 融入场景描述 |
| `通用设定.氛围基调` | 场景环境（氛围） | 融入场景描述 |
| `场景描述` | 场景环境 + 主体位置 | 融入对应镜头段首 |
| `站位/调度` | 主体动作 + 空间关系 | 融入主体动作描述 |
| `人物心理活动` | （不直接写入） | 转化为情绪外化身体细节（查 `references/action-emotion.md` 对照表） |
| `表演/微表情` | 动作细节 + 情绪外化 | 用对照表外化，补肢体细化+程度量化 |
| `景别` | 运镜（景别） | 融入镜头段首 |
| `摄影机角度` | 运镜 | 融入镜头段首 |
| `摄影机运动` | 运镜 | 每镜头限 1 种运镜方式 |
| `焦距景深` | 运镜（景深） | 融入运镜描述 |
| `光线` | 光影色调 | 融入场景描述 |
| `氛围` | 场景环境 | 融入场景描述 |
| `台词` | 台词 | **逐字保留**，转 `{}` 语法 |
| `音效` | 音效 | 转 `<>` 语法，仅 `enable_sound=true` 时保留 |
| `剪辑转场` | 镜头间衔接 | 融入时序叙事的镜头切换 |
| `后期特效` | 画面描述 | 融入对应镜头画面 |

### 精简 MD 模式适配

精简模式的组文件已是讲戏式叙事（一段一镜），适配更轻量：

1. **台词转换**：将 `角色名："台词"` 格式转为 `{台词}`（逐字保留）
2. **运镜检查**：检查每段是否含多种运镜，若有则标注拆分建议
3. **约束补全**：若末尾缺少画质/约束收尾段，从通用设定提取风格质感补全
4. **禁用元素清除**：移除任何配乐描述、字幕生成语法

### 适配步骤

```
Step 1：读取组文件内容（JSON 或 MD），解析镜头列表
Step 2：逐镜头映射字段 → Seedance 要素
  ├─ 场景建立：场景名称 + 光线 + 色调 + 氛围 → 首镜头场景段
  ├─ 主体动作：站位/调度 + 表演/微表情 → 动作描述（情绪外化、肢体细化）
  ├─ 运镜：景别 + 角度 + 运动 + 景深 → 单一运镜指令
  ├─ 台词：逐字提取 → {} 语法
  └─ 音效：提取 → <> 语法（仅 enable_sound=true）
Step 3：按镜头时序组装叙事段落（镜头1 / 镜头2 / ...）
Step 4：追加全局收尾段（画质词 + 风格词 + 稳定性约束）
Step 5：输出优化提示词文本 → 交 video-director-libtv 拼装
```

### 适配铁律

1. **台词逐字保留**：从组文件台词字段提取原文，用 `{}` 包裹，不得改写、删减、概括
2. **心理活动外化**：`人物心理活动` 字段不得直接写入提示词，须转化为身体细节（如"紧张"→"手指不停敲击桌面、呼吸急促"）
3. **运镜单一**：每个镜头段落只含 1 种摄影机运动，若原字段含多种则取主导运镜
4. **禁止配乐/字幕**：不添加音乐 `（）` 描述，不添加字幕 `【】` 生成语法
5. **关键信息不遗漏**：场景、主体特征、核心动作、台词、运镜方向均须保留，不得因"精简"而丢失
6. **不添加原文件没有的创意内容**：适配是重组而非创作，不得新增原分镜未包含的情节、角色或动作

### 输出格式（适配模式）

适配模式不输出"优化说明/素材建议/风险提示"（这些适用于独立优化场景），仅输出可直接使用的提示词文本：

```
[场景建立段：场景名 + 光影色调 + 氛围]

镜头1：[运镜指令] + [主体动作与情绪外化] + [场景位置变化] + [台词{}] + [音效<>]

镜头2：...

[全局收尾：画质词，风格词，人物面部稳定不变形，动作自然流畅，无卡顿无闪烁]
```

此文本由 video-director-libtv 包裹引用行 + 约束行 + `---` 分隔线后，作为 `--prompt` 内容投递。

## 输出格式

优化结果按以下结构交付：

1. **优化后提示词**（可直接使用的完整文本）
2. **优化说明**（3–5 条要点：改了什么、为什么）
3. **素材建议**（如适用：建议补充的参考素材及其功能角色）
4. **风险提示**（如适用：可能触发的已知问题及预防措施，引用 troubleshooting）
