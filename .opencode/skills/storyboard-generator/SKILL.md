# 分镜脚本生成

将分集剧本拆解为**场→组→镜**三级结构化 JSON，输出分镜脚本与独立组 JSON。

**核心原则：**
- Agent 用自身 LLM **理解剧本、创作分镜**，直接写文件
- expand_scenes_to_groups.py 仅做最后一步**机械拆分**（场→组展开）
- 不依赖任何 Python 管线脚本做内容校验——Agent 自己保证格式正确

---

## 工作流程

```
┌─────────────────────────────────────────────────────────┐
│  1. 读剧本 + 读设定                                      │
│     → 理解故事内容、画面描述、口播文案                      │
│                                                         │
│  2. 用自身 LLM 创作分镜 JSON                              │
│     → 按下方格式规则生成场→组→镜三级结构                    │
│     → 每个镜头包含全部 17 个字段                           │
│                                                         │
│  3. 写文件                                               │
│     → 直接写入 {剧集号}/分镜/分镜脚本.json                 │
│                                                         │
│  4. [可选] 机械拆分成组                                   │
│     → 如需分组文件，调用 expand_scenes_to_groups.py        │
│     → 输出到 {剧集号}/分镜/分组/组{N}.json                │
└─────────────────────────────────────────────────────────┘
```

---

## 第一步：读取剧本

读取原始剧本或分集剧本，找到对应剧集的表格数据：
- **画面内容**：AI动效描述 + 产品展示清单
- **口播文案**：旁白配音文本
- **时长**：单集15-30秒

---

## 第二步：按需读取设定文件

如需参考全局设定、角色/场景/道具设定，从以下路径读取：
```
project/{项目名}/全局依赖/
├── 全局设定/
├── 角色设定/
├── 场景设定/
└── 道具设定/
```

## 第三步：输出格式要求

Agent 用自身 LLM 生成 JSON，必须为**场→组→镜**三级结构：

```json
[
  {
    "场号": 1,
    "场名称": "...",
    "场叙事概述": "...",
    "场转场": "切",
    "场总时长": "18",
    "通用设定": {
      "风格": "...",
      "场景名称": "...",
      "全局光线基调": "...",
      "全局色彩调性": "...",
      "全局氛围基调": "..."
    },
    "组列表": [
      {
        "组号": 1,
        "组时长": "6",
        "组叙事概述": "...",
        "组转场": "切",
        "镜头列表": [
          {
            "镜号": 1,
            "开始/结束时间": "0-3",
            "时长": "3",
            "场景描述": "...",
            "站位/调度": "...",
            "人物心理活动": "...",
            "表演/微表情": "...",
            "景别": "...",
            "摄影机角度": "...",
            "摄影机运动": "...",
            "焦距景深": "...",
            "光线": "...",
            "氛围": "...",
            "台词": "...",
            "音效": "...",
            "剪辑转场": "...",
            "后期特效": "..."
          }
        ]
      }
    ]
  }
]
```

### 场级连贯性规则

**规则 1：调度设计连贯** — 同一场内相邻组之间人物调度和空间走位形成连续空间叙事线。关键定位物位置一致，人物相对位置不突变，走动方向组间保持一致。

**规则 2：不越轴（180° 规则）** — 同一场内所有组摄影机轴线方向保持一致。如需越轴，中间必须插入中性镜头缓冲。

**规则 3：剧情与蒙太奇连贯** — 组间叙事推进自然流畅，情绪落点引导下一组的情绪起点。

### 硬约束

1. **台词时长**：每个含台词镜头，时长 ≥ 汉字数 ÷ 4 + 0.5 秒
2. **组时长**：每组镜头时长之和 ≤ 15 秒
3. **组镜头数**：每组 ≤ 9 个镜头
4. **长镜头独占**：≥10 秒的镜头独占一组
5. **快切独立成组**：快切镜头组单独成组
6. **台词格式**：`台词` 字段以`旁白：`开头（本项目为旁白类商业片），与原始剧本逐字一致
7. **字段完整**：每个镜头必须包含全部 17 个字段
8. **时间连续**：同组内首镜从 0 开始
9. **字数范围**：光线/氛围 60~120 字，表演/微表情 60~120 字，站位/调度 80~160 字，人物心理活动 80~160 字，场景描述 60~100 字
10. **纯中文输出**（除 f/2.8 等技术表达外）
11. **通用设定在场级统一定义**
12. **场级连贯性**：遵守调度连贯、不越轴、剧情蒙太奇连贯三条规则
13. **音频规则**：仅允许对白和音效，禁止背景音乐
14. **禁止冗余描述**：去掉"仿佛""让观众感受到""传递出""营造出"等引导性修辞，描述像导演给摄影师的指令一样精炼

---

## 第四步：生成分镜 JSON 并写入

### 操作步骤

**Step 1：用自身 LLM 生成分镜 JSON**
严格按照上文的 JSON 格式、场级连贯性规则和硬约束生成。

**Step 2：写入文件**
直接写入 `{剧集号}/分镜/分镜脚本.json`

```json
[
  {
    "场号": 1,
    "场名称": "...",
    "场叙事概述": "...",
    ...
  }
]
```

---

## 第五步：[可选] 拆分为独立组文件

如需独立组 JSON（供 video-director 逐组使用），调用 `expand_scenes_to_groups.py`：

```powershell
.venv\Scripts\python.exe ".opencode/skills/storyboard-generator/scripts/expand_scenes_to_groups.py" `
  --input "project/{项目名}/{剧集号}/分镜/分镜脚本.json" `
  --output-dir "project/{项目名}/{剧集号}/分镜/分组/"
```

这一步是纯机械拆分：将场级 `通用设定` 注入到每个组中，生成独立组 JSON 文件。

## 最终产出结构

```
{剧集号}/
└── 分镜/
    ├── 分镜脚本.json              ← Agent 用 LLM 直接生成（完整场→组→镜）
    └── 分组/                     ← [可选] expand_scenes_to_groups.py 拆出
        ├── 组1.json
        ├── 组2.json
        └── ...
```

## 自检清单

生成完成后确认：
- [ ] 格式为场→组→镜三级结构
- [ ] 每个镜头包含全部 17 个字段
- [ ] 口播文案按节奏分配到各镜头的`台词`字段
- [ ] 画面描述具体可执行，不模糊
- [ ] 遵守硬约束（时长、字数、组限制等）
- [ ] 无背景音乐，无画面文字
