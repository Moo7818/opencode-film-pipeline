# 阶段二：episode_storyboard_images — 分镜图绘制

**独立阶段（仅当 project_config.json 中 use_storyboard_images=true 时执行）**：此阶段在 `episode_storyboard_script`、`episode_character_ref`、`episode_prop_ref`、`episode_scene_ref` 之后执行，分镜图可参考剧集级场景/道具变化。`use_storyboard_images=false` 或未设置时跳过此阶段，video-director 将以角色/场景参考图为主要参考素材。

> **两种模式均支持分镜图绘制**。详细模式从 `组{N}.json` 读取，精简模式从 `组{N}.md` 读取。

---

## Step 1：收集参考图清单

分镜图绘制前，**Agent 须列出各参考图目录下的具体文件**，供 Step 2 逐组引用。

| 参考图类型 | 来源路径 | 说明 |
|-----------|---------|------|
| 角色参考图 | `project/{项目名}/全局依赖/角色设定/角色参考图/*.png` | 全局角色参考图（含妆造匹配） |
| 场景参考图 | `project/{项目名}/{剧集号}/场景参考图/*.png` | 剧集级场景参考图（含本集场景变化） |
| 道具参考图 | `project/{项目名}/{剧集号}/道具参考图/*.png` | 剧集级道具参考图（含本集道具状态变化） |
| 风格参考图 | `project/{项目名}/前期采样/风格/*.png` | 全局视觉风格基准（色调、光影氛围、画面质感） |

> 如剧集级参考图目录不存在（无变化场景/道具），回退使用全局基准图：`全局依赖/场景设定/场景参考图/` 和 `全局依赖/道具设定/道具参考图/`。
>
> **道具全局基准文件名含出现场合**：回退引用全局道具基准图时，文件名格式为 `{道具名}_{出现场合}_基准.png`。需读取 `全局依赖/道具设定/具体设定/{道具名}.md` 中的 `出现场合` 字段，匹配正确的基准文件。仅引用该道具 `出现场合` 包含当前剧集号的基准图，**禁止**引用不属于本集的道具资产。

**Agent 执行**：用 LS 工具列出上述目录中的 `.png` 文件，记录完整路径。例如：

```
角色参考图/
  掌柜.png
  小二.png
  赵胖.png
场景参考图/
  春生茶肆_破败.png
  春生茶肆_翻新.png
道具参考图/
  袋泡茶.png
风格/
  水墨风基准.png
```

---

## 参考图排序优先级

`images` 数组中的参考图按以下优先级排列：

1. **角色参考图**（最高优先级）— 主要角色排首位
2. **场景参考图**（第二优先级）
3. **道具参考图**（第三优先级）
4. **风格参考图**（第四优先级）

**硬约束**：角色和场景参考图必须位于前五个参考中。

---

## Step 2：Agent 直接编写任务表 JSON

Agent 使用 Write 工具直接编写 `分镜图_任务表.json`，保存到 `project/{项目名}/{剧集号}/分镜/分镜图_任务表.json`。

### 2.1 读取分镜内容

读取 `{剧集号}/分镜/分组/` 目录下的组文件：
- **详细模式**：`组{N}.json` — 从 `组叙事概述`、`通用设定`、`组转场`、`镜头列表` 获取组信息
- **精简模式**：`组{N}.md` — 从正文获取叙事概述和分镜描述

### 2.2 逐组构建 task

对每个组构建一个 task 对象，包含以下字段：

| 字段 | 值 | 说明 |
|------|-----|------|
| `prompt` | 见下方模板 | 生成提示词 |
| `model` | `"gpt-image-2-vip"` | **硬约束**，禁止使用其他模型 |
| `imageSize` | `"1K"` | 分辨率等级 |
| `aspectRatio` | `"16:9"` | **默认值**，不声明网格布局和镜头数，生图模型自由发挥画面排列 |
| `filename` | `"组{组号}.png"` | 如 `组1.png` |
| `images` | 具体文件路径数组 | 按 2.3 匹配 |

#### prompt 模板（严格遵循）

```
{参考图标签1}，{参考图标签2}，...

绘制分镜图，风格：{风格}，画面无字幕。

{分镜叙事内容}
```

**结构说明**：

- **第一行**：参考图标签，中文逗号 `，` 分隔，无句号
- **空行**
- **第二行**：固定指令 `绘制分镜图，风格：{风格}，画面无字幕。`（句号结尾）
- **空行**
- **第三段起**：分镜叙事内容

**风格**：取自该组通用设定中的 `风格质感` 字段（如 `真人实拍电影级质感`、`水墨风人物动画`）。

**分镜叙事内容**：
- 精简模式：`组叙事概述` + 空行 + `分镜描述`（来自 `组{N}.md` 正文）
- 详细模式：`组叙事概述` + 空行 + 镜头列表 JSON（来自 `组{N}.json` 的 `镜头列表` 字段）

#### 参考图标签格式

| 类型 | 格式 | 示例 |
|------|------|------|
| 角色 | `{角色名}角色参考第{中文序数}张图片` | `掌柜角色参考第一张图片` |
| 场景 | `{场景名}场景参考第{中文序数}张图片` | `茶馆场景参考第二张图片` |
| 道具 | `{道具名}道具参考第{中文序数}张图片` | `袋泡茶道具参考第三张图片` |
| 风格 | `整体风格特征参考第{中文序数}张图片` | `整体风格特征参考第四张图片` |

> 中文序数：第一张、第二张、第三张……与 `images` 数组顺序一一对应。

### 2.3 逐组匹配参考图

对每个组，根据该组的角色出场、场景位置、道具使用，从 Step 1 收集的参考图清单中选取具体文件：

1. **角色**：该组出场的角色，每人一张参考图
2. **场景**：该组发生的场景，选对应场景参考图
3. **道具**：该组出现的道具，选对应道具参考图（无道具可省略）。优先使用剧集级道具参考图（`{剧集号}/道具参考图/`），无剧集级时回退全局基准图（文件名含 `_{出现场合}_基准`，需确认该道具的 `出现场合` 包含当前剧集号）
4. **风格**：统一引用全局风格参考图

将选中的文件**完整路径**写入 `images` 数组，按 角色 → 场景 → 道具 → 风格 排序。prompt 第一行的标签序号与 images 数组顺序一一对应。

> **按需引用**：仅引用该组实际涉及的角色/场景/道具，不引入无关参考图。

### 2.5 硬约束汇总

- `model` 必须为 `gpt-image-2-vip`
- `aspectRatio` 必须为 `16:9` 或 `9:16`
- `images` 数组**不得为空**——分镜图必须引用角色/场景参考图
- `images` 中的路径必须为**具体文件**（含扩展名 `.png`/`.jpg`），禁止目录路径
- 角色和场景参考图必须位于**前五个**参考中
- `images` 按 角色 → 场景 → 道具 → 风格 排序
- prompt 中参考图标签数量必须与 `images` 数组长度**一致**
- prompt 严格遵循模板：第一行参考图标签 → 空行 → 绘制指令行 → 空行 → 叙事内容

## Step 3：校验

编写完成后，运行校验脚本审核语法和引用一致性：

```powershell
# Windows
.venv\Scripts\python.exe ".opencode\skills\storyboard-generator\scripts\validate_task_table.py" `
  --check "project\{项目名}\{剧集号}\分镜\分镜图_任务表.json" --verbose
```

校验项：
1. JSON 语法正确性
2. 模型必须为 `gpt-image-2-vip`
3. 画面比例必须为 `16:9` 或 `9:16`
4. `images` 数组不得为空
5. `images` 路径必须为具体文件（非目录）
6. prompt 中 image 引用数量与 `images` 数组一致
7. 参考图优先级排序：角色 → 场景 → 道具 → 风格
8. 角色和场景参考图必须在前五个参考中

> **校验未通过时禁止进入 Step 4**。根据错误信息修正 JSON 后重新校验。

---

## Step 4：交美术指导执行批量生图

将 `分镜图_任务表.json` 交 art-director 执行批量生图，分镜图存入 `project/{项目名}/{剧集号}/分镜/分镜图_*.png`。

## 可选辅助：generate_task_table.py

如需快速生成骨架再手动修改，可使用 `generate_task_table.py` 生成初始任务表。但**推荐直接手写**——Agent 已掌握分镜内容和参考图清单，直接编写可避免骨架→修改的两步开销。

```powershell
# 自动检测参考图目录
.venv\Scripts\python.exe ".opencode\skills\storyboard-generator\scripts\generate_task_table.py" `
  --groups-dir "project\{项目名}\{剧集号}\分镜\分组\" `
  --output-dir "project\{项目名}\{剧集号}\分镜\" `
  --output-name "分镜图_任务表.json" `
  --aspect-ratio 9:16 `
  --project-dir "project\{项目名}" `
  --episode "{剧集号}"
```

> 脚本生成的骨架使用旧版 prompt 格式（含网格布局、通用设定 JSON 等），`images` 为目录路径、标签为泛化形式。需手动改为新模板格式并替换为具体文件路径后方可校验。
