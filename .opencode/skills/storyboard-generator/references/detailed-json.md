# 精细版分镜创作说明

> 结构化 JSON 格式，每镜头 17 个独立字段，供 AI 视频生图管线消费。

---

## 1. 格式定义 ← 必读

```json
[
  {
    "场号": 1,
    "场名称": "...",
    "场叙事概述": "...",
    "场转场": "切",
    "场总时长": "18",
    "通用设定": {
      "风格": "...",
      "场景名称": "...",
      "全局光线基调": "...",
      "全局色彩调性": "...",
      "全局氛围基调": "..."
    },
    "组列表": [
      {
        "组号": 1,
        "组时长": "6",
        "组叙事概述": "...",
        "组转场": "切",
        "镜头列表": [
          {
            "镜号": 1,
            "开始/结束时间": "0-3",
            "时长": "3",
            "场景描述": "...",
            "站位/调度": "...",
            "人物心理活动": "...",
            "表演/微表情": "...",
            "景别": "...",
            "摄影机角度": "...",
            "摄影机运动": "...",
            "焦距景深": "...",
            "光线": "...",
            "氛围": "...",
            "台词": "...",
            "音效": "...",
            "剪辑转场": "...",
            "后期特效": "..."
          }
        ]
      }
    ]
  }
]
```

### 场级字段

| 字段 | 必填 | 说明 |
|------|------|------|
| `场号` | ✓ | 整数，从1开始 |
| `场名称` | ✓ | 概括本场场景/事件 |
| `场叙事概述` | ✓ | 一句话描述本场叙事功能 |
| `场转场` | ✓ | 本场进入方式 |
| `场总时长` | ✓ | 字符串，秒数 |
| `通用设定` | ✓ | 对象，含风格/场景名称/光线基调/色彩调性/氛围基调 |
| `组列表` | ✓ | 数组，至少1个组 |

### 组级字段

| 字段 | 必填 | 说明 |
|------|------|------|
| `组号` | ✓ | 组内编号 |
| `组时长` | ✓ | 本组总时长（秒） |
| `组叙事概述` | ✓ | 本组叙事功能 |
| `组转场` | ✓ | 本组进入方式 |
| `镜头列表` | ✓ | 数组，1~9镜 |

### 镜头级字段（17个）

| # | 字段 | 必填 | 字数范围 | 说明 |
|---|------|------|---------|------|
| 1 | `镜号` | ✓ | — | 组内编号，从1开始 |
| 2 | `开始/结束时间` | ✓ | — | 如 `"0s - 3s"`，首镜从0开始 |
| 3 | `时长` | ✓ | — | 字符串，秒数 |
| 4 | `场景描述` | ✓ | 20~40字 | 本镜画面核心内容 |
| 5 | `站位/调度` | ✓ | 25~50字 | 人物位置、走位、空间关系 |
| 6 | `人物心理活动` | ✓ | 10~25字 | 角色内在情绪/动机 |
| 7 | `表演/微表情` | ✓ | 15~30字 | 动作+眼神方向+表情变化 |
| 8 | `景别` | ✓ | — | 极远景/远景/全景/中景/近景/特写 |
| 9 | `摄影机角度` | ✓ | — | 平拍/俯拍/仰拍/侧面/过肩等 |
| 10 | `摄影机运动` | ✓ | — | 固定/推/拉/摇/移/跟/手持/航拍 |
| 11 | `焦距景深` | ✓ | — | 如 `f/2.8 浅景深` |
| 12 | `光线` | ✓ | 20~40字 | 光源方向、色温、光质、明暗 |
| 13 | `氛围` | ✓ | 15~30字 | 场景情绪基调 |
| 14 | `台词` | ✓ | — | `旁白：`开头，与剧本逐字一致 |
| 15 | `音效` | ✓ | — | 环境音、动作音、特殊音效 |
| 16 | `剪辑转场` | ✓ | — | 切/叠化/淡入淡出/划等 |
| 17 | `后期特效` | ✓ | — | 无 或 具体特效描述 |

## 2. 硬约束 ← 必读

### 时长与结构

1. **台词时长** — 每含台词镜头，`时长 ≥ 汉字数 ÷ 4 + 0.5 秒`
2. **组时长** — 每组镜头时长之和 ≤ 15 秒
3. **组镜头数** — 每组 ≤ 9 个镜头
4. **长镜头独占** — ≥10 秒的镜头独占一组
5. **快切独立成组** — 快切镜头组不与叙事镜头混组
6. **时间连续** — 同组内首镜从 `0` 开始

### 内容格式

7. **台词格式** — `台词` 字段以 `旁白：` 开头，与原始剧本逐字一致
8. **字段完整** — 每个镜头必须包含全部 17 个字段
9. **字数范围** — 按上表各字段字数范围约束
10. **纯中文输出** — 除非技术表达（如 `f/2.8`）
11. **通用设定在场级统一定义** — 组/镜头级不得出现
12. **禁止冗余描述** — 去掉"仿佛""让观众感受到""传递出""营造出"等

### 叙事与镜头语言

13. **场级连贯性** — 调度连贯、不越轴、蒙太奇连贯（见 `SKILL.md` 共同规则）
14. **音频规则** — 仅对白和音效，禁止背景音乐
15. **表演/微表情必须包含眼神方向** — 每镜描述角色视线关系（望向镜头/看向产品/与对手对视等）

## 3. 产出流程

**Step 1-2：** 读取剧本 → 读取设定文件（`project/{项目名}/全局依赖/`）

**Step 3：** 用自身 LLM 生成分镜 JSON，严格按上述格式、连贯性规则和硬约束

**Step 4：** 写入 `{剧集号}/分镜/分镜脚本.json`

**Step 5：[可选] 拆分为独立组文件 + 生成任务表**
```powershell
.venv\Scripts\python.exe ".opencode/skills/storyboard-generator/scripts/run_pipeline.py" --build `
  --pipeline-dir "project/{项目名}/{剧集号}/.pipeline" `
  --output-dir "project/{项目名}/{剧集号}/分镜"
```
追加 `--with-task-table` 同时生成生图任务表。
管线自动完成：JSON 校验修复 → 场→组展开 + 通用设定注入 → 输出独立组 JSON → [可选] 分镜图任务表。

### 产出结构

```
{剧集号}/
└── 分镜/
    ├── 分镜脚本.json            ← Agent 用 LLM 直接生成
    ├── 分组/                    ← 管线拆出
    │   ├── 组1.json
    │   └── 组2.json …
    └── 分镜图_任务表.json        ← [可选]
```

### 字段可选参数参考

以下为各枚举字段的常用参数值。自由文本字段（场景描述、站位/调度、人物心理活动、表演/微表情、光线、氛围、台词、音效、后期特效）参考 `text-format.md` 中的参数说明并融合到对应字段描述中。

#### 景别

| 参数值 | 画面范围 | 叙事功能 |
|--------|---------|---------|
| `极远景` | 人物极小，环境占绝对主导 | 建立宏大空间感、史诗开篇 |
| `远景` | 人物全身，环境占主导 | 交代人物与环境关系 |
| `全景` | 人物全身充满画框 | 展示人物整体姿态、服装、走位 |
| `中全景` | 膝盖以上 | 兼顾动作与环境 |
| `中景` | 腰部以上 | 对话基础景别 |
| `中近景` | 胸部以上 | 专注表情与台词 |
| `近景` | 肩部以上 | 强调情绪、微表情 |
| `特写` | 局部（眼/嘴/手/道具） | 强调关键信息、情感爆发 |
| `大特写` | 极细微细节 | 极度放大情绪 |
| `微距` | 极小物体全屏 | 产品细节强调 |

支持组合使用：`极远景→远景`、`中景→近景`（表示景别推进/拉远的变化）。

#### 摄影机角度

| 参数值 | 说明 |
|--------|------|
| `平拍` / `Eye Level` | 与人物视线齐平，中性客观 |
| `俯拍` / `High Angle` | 高于视线，人物显弱小 |
| `仰拍` / `Low Angle` | 低于视线，人物显高大 |
| `过肩` / `OTS` | 越过一人肩膀拍另一人 |
| `正面` / `Frontal` | 正对人物，直面观众 |
| `侧面` / `Profile` | 90度侧对，孤独/旁观感 |
| `侧面45度` / `Three-Quarter` | 自然生动的对话角度 |
| `背面` / `Over-the-Back` | 从背后拍摄，跟随感 |
| `顶拍` / `Top Shot` | 正上方垂直俯拍，上帝视角 |
| `底拍` / `Ground Level` | 贴地仰拍，压迫感 |
| `主观视角` / `POV` | 模拟角色视线 |
| `荷兰角` / `Dutch Angle` | 摄影机倾斜，不安感 |

#### 摄影机运动

| 参数值 | 说明 | 适用场景 |
|--------|------|---------|
| `固定` | 静止不动 | 对话、静态叙事 |
| `推` / `Push In` | 靠近主体 | 情绪升级、揭示细节 |
| `拉` / `Pull Out` | 远离主体 | 揭示环境、疏离感 |
| `摇` / `Pan` | 机身水平旋转 | 跟拍横向移动、揭示空间 |
| `移` / `Track` | 横向平移 | 平行跟拍、展示纵深 |
| `跟` / `Follow` | 跟随主体 | 代入感、追逐场景 |
| `升` / `Boom Up` | 垂直上升 | 揭示全貌 |
| `降` / `Boom Down` | 垂直下降 | 进入场景 |
| `环绕` / `Arc` | 弧形绕主体运动 | 仪式感、强调中心 |
| `手持` / `Handheld` | 人工晃动 | 纪实感、紧张感 |
| `POV` | 主观视角运动 | 角色代入 |
| `航拍` / `Aerial` | 无人机/直升机 | 宏大场景 |
| `轨道` / `Dolly` | 轨道车平滑推进 | 专业级平稳运镜 |
| `摇臂` / `Crane` | 大范围升降+平移 | 大型场景调度 |
| `斯坦尼康` / `Steadicam` | 稳定器跟拍 | 长镜头无缝穿梭 |
| `dolly zoom` | 推拉+变焦同步 | 眩晕感、内心崩溃 |
| `甩镜头` / `Whip Pan` | 快速横向急甩 | 快节奏转场 |

支持组合：`航拍运动→慢推`、`固定→缓慢推`。

#### 焦距景深

| 参数值 | 画面效果 |
|--------|---------|
| `超广角 14-24mm` | 视野极广，透视夸张 |
| `广角 24-35mm` | 视野宽阔 |
| `标准 35-50mm` | 接近人眼自然观感 |
| `中长焦 85-135mm` | 空间压缩，背景虚化 |
| `长焦 200mm+` | 强烈空间压缩 |
| `超长焦 400mm+` | 极远距离 |
| `鱼眼 6-16mm` | 圆形畸变，特殊效果 |
| `浅景深 f/1.2-f/2.8` | 主体清晰背景虚化 |
| `中景深 f/4-f/5.6` | 前后适度清晰 |
| `深景深 f/8-f/16` | 全景深清晰 |
| `微距` | 极近距离放大 |

#### 剪辑转场

| 参数值 | 效果 |
|--------|------|
| `切` / `Cut` | 瞬间切换，最基础 |
| `叠化` / `Dissolve` | 前淡出后淡入重叠，时间过渡 |
| `淡入` / `Fade In` | 从黑场显现 |
| `淡出` / `Fade Out` | 隐入黑场 |
| `划像` / `Wipe` | 线扫过切换 |
| `闪白` / `White Flash` | 瞬间白场 |
| `闪黑` / `Black Flash` | 瞬间黑场 |
| `匹配剪辑` / `Match Cut` | 形状/运动匹配过渡 |
| `跳跃剪辑` / `Jump Cut` | 同一主体时间跳跃 |
| `L Cut` | 前镜音频延续到后镜 |
| `J Cut` | 后镜音频提前在前镜出现 |

#### 其他自由文本字段写作指引

| 字段 | 字数 | 应包含内容 | 参考 |
|------|------|-----------|------|
| `场景描述` | 20-40字 | 核心画面内容、环境要素、空间氛围 | 参考 text-format.md 的光线/色彩/氛围参数 |
| `站位/调度` | 25-50字 | 人物空间位置、走位方向、姿态变化、前后景关系 | 包含相对位置、运动方向 |
| `人物心理活动` | 10-25字 | 角色内心状态、情绪动机、心理变化 | 简洁，不冗长 |
| `表演/微表情` | 15-30字 | 动作细节+眼神方向+表情变化+情绪状态 | **必须含眼神方向** |
| `光线` | 20-40字 | 光源方向+色温+光质+明暗+光影层次 | 参考 text-format.md 的光位和色温表 |
| `氛围` | 15-30字 | 场景情绪基调、空间氛围 | 参考 text-format.md 的氛围参数 |
| `台词` | — | `旁白：`开头，逐字剧本 | 做人性化适配（见 SKILL.md 通用约束） |
| `音效` | — | 环境音、动作音、特殊音效 | 具体到声源和质感 |
| `后期特效` | — | 无 或 具体特效描述 | 如"落点加震动波纹+白色粒子消散" |
