# 讲戏版分镜创作说明

> 纯文本自然语言分镜，保留场→组→镜骨架，镜头级内容为自然语言段落。
> 供真人导演/演员读本、现场拍摄使用。

---

## 1. 格式定义 ← 必读

```
# 场{N}：{场名称}
总时长：{N}s｜场转场：{转场方式}
风格：{风格} | 场景：{场景名称} | 光线基调：{光线基调}
色彩调性：{色彩调性} | 氛围基调：{氛围基调}

## 组{N}：{组叙事概述}【{组时长}s】
组转场：{转场方式}

镜号{N}｜{开始时间}s - {结束时间}s｜时长{N}s

{分镜描述 — 自然语言段落}

镜号{N+1}｜{时间}s - {时间}s｜时长{N}s

{分镜描述}
```

### 格式元素

| 元素 | 说明 |
|------|------|
| `# 场{N}` | 场级标题，后跟场名称 |
| 场通用设定 | 场标题后、组标题前的键值行（风格/场景/光线/色彩/氛围） |
| `## 组{N}` | 组级标题，后跟叙事概述和时长 |
| `镜号{N}｜` | 镜头标识行，含时间范围和时长 |
| 分镜描述 | 自然语言段落（见下文要素清单） |
| 台词 | 以中文引号 `""` 标注在分镜描述中 |

### 分镜描述段落要素

单个镜头的描述段落应自然融合以下所有要素，描述时应准确选用参数词汇（完整参数库见"详细参考→字段可选参数参考"）：

- **运镜**：固定/推/拉/摇/移/跟/升降/环绕/手持/POV/航拍/轨道/摇臂/斯坦尼康/dolly zoom
- **景别**：极远景/远景/全景/中景/近景/特写/大特写/微距
- **摄影角度**：平拍/俯拍/仰拍/过肩/正面/侧面/背面/顶拍/底拍/主观视角
- **人物站位与调度**：明确人物相对空间位置、走位方向、姿态变化
- **表演与微表情**：动作细节+眼神方向+表情变化+情绪状态，眼神必须交代望向何处
- **台词**：以引号标注，附带语气/节奏/情绪提示（如"压低声音""尾音上扬""语速放慢"）
- **光线与色彩**：主光源方向+色温+光质（硬/柔）+色彩倾向
- **环境与氛围**：背景状态+空间氛围+画面层次（前后景关系、虚化/清晰）
- **转场**：段间以 `切。` `叠化。` `淡出。` `闪白。` 等标注

### 台词时长核算

> **引号内汉字数 ÷ 4 + 0.5 ≤ 镜头时长（秒）**

Agent 自行在创作时核算。例：`"他就这德行。"` = 5汉字 → 5÷4+0.5=1.75s，向上取整2s ✅

---

## 2. 产出流程

**Step 1-2：** 读取剧本 → 按需读取设定文件（`project/{项目名}/全局依赖/`）

**Step 3：** 创作纯文本分镜，严格按上述格式和共同规则（见 `SKILL.md` 共同规则章节）

**Step 4：** 写入 `{剧集号}/分镜/分镜脚本.txt`

**Step 5：** 将每个组的镜头（含场级上下文）写入独立文件：
```
{剧集号}/分镜/分组/组{N}.txt
```
每个组文件自我包含：场号 + 通用设定 + 组头信息 + 该组所有镜头

### 产出结构

```
{剧集号}/
└── 分镜/
    ├── 分镜脚本.txt       ← Agent 直接生成（完整文本）
    └── 分组/
        ├── 组1.txt
        └── 组2.txt …
```

## 3. 详细参考 ← 需要时往下读

### 完整示例：分镜脚本.txt

```
# 场1：餐厅对峙
总时长：12s｜场转场：切
风格：写实生活化 | 场景：小饭馆内 | 光线基调：暖黄吊灯主光
色彩调性：暖色调局部冷色对比 | 氛围基调：紧张中带幽默

## 组1：王姐与彪哥对峙【6s】
组转场：切

镜号9｜0s - 2s｜时长2s

切。固定机位，近景，王姐正面偏右。

抱臂姿态不动，重心从右腿换到左腿。视线从彪哥方向缓慢移向小美，再移回彪哥。眉毛不抬不低，嘴角微向左撇。"他就这德行。"语气平稳，尾音下沉，说完嘴角有极轻微上扬，嘴唇合拢轻咂一声。暖黄吊灯均匀照在脸上，碎花围裙花色可辨。彪哥在左侧虚化成暖色轮廓，发出一声极轻的泄气声。

切。

镜号10｜2s - 6.5s｜时长4.5s

手持微横移，侧面约七十度角。

彪哥从僵住状态弹起来，前脚朝小美方向迈出一步，肩部耸起。右臂抬起，手掌在嘴外侧弯成遮音手势，身体前倾约十五度，膝盖微弯。眼睛眯起，眉毛下压，压低声音："那我要是装一百台……"语速放慢，眉毛随"一百台"上扬一次，停顿半秒，"……是不是还能倒赚点？"尾音扬起，嘴角控制不住上扬。

暖黄吊灯从上方照明，遮音手在面部投下局部阴影。小美在右侧入画虚化，冷白昼光打在彪哥右肩形成冷色边缘。工装鞋蹭地砖的轻微嘎吱声。

切。

## 组2：小美介入【5.5s】
组转场：切

镜号11｜6.5s - 9.5s｜时长3s

固定机位，餐桌对面平拍。

王姐右手从抱臂中松开，白抹布滑到指尖。右臂向后预摆，然后从后向前抡出，抹布脱手，"啪"一声闷响落在宣传单旁边约二十厘米处。眉头骤锁，鼻翼翕张。"你先把欠我的工资结了！"语气急促，"欠我的"咬字加重，"结"字声调上扬。说完嘴唇紧抿，胸腔起伏两次。远景彪哥被吓得肩部耸起后缓缓放下。

白抹布落在格子台布上，与宣传单荧光黄绿形成色彩对比。后期在落点加轻微震动波纹和几颗微小白色粒子消散。

切。

镜号12｜9.5s - 12s｜时长2.5s

固定机位，小美正面偏右，全身入画。

右手从宣传单上抬起，左手叉腰。头先缓慢转向王姐，耗时约零点八秒，眉毛微挑，嘴微张。再快速转回彪哥方向，约零点五秒。"姐，您这儿还招人吗？"语气轻快，尾音上扬。说完嘴角绷不住上扬，眼睛眯起，露齿而笑——整场第一次真笑。笑声短促清脆，约零点三秒。

暖黄吊灯均匀照明，台布上宣传单和抹布在画面下部形成两个色块。后期在笑声时画面亮度微升，渐暗至黑场，笑声尾音渐消。

切。黑场。
```

### 字段可选参数参考

以下为各字段的常用参数值及示例，创作时按需选用组合。

#### 运镜

| 运镜方式 | 说明 | 适用场景 |
|---------|------|---------|
| 固定镜头 | 摄影机静止不动 | 对话、静态叙事、强调注视感 |
| 推（Push In） | 摄影机匀速/加速靠近主体 | 强调情绪升级、揭示细节、进入内心 |
| 拉（Pull Out） | 摄影机匀速/加速远离主体 | 揭示环境、制造疏离感、落幕感 |
| 摇（Pan） | 机身水平旋转 | 跟拍横向移动主体、揭示空间关联 |
| 移（Track/Dolly） | 摄影机横向平移 | 平行跟拍、展示环境纵深、制造运动感 |
| 跟（Follow） | 摄影机跟随主体移动 | 第一人称代入感、追逐场景 |
| 升（Boom Up） | 摄影机垂直上升 | 揭示全貌、制造俯瞰视角 |
| 降（Boom Down） | 摄影机垂直下降 | 进入场景、降低压迫感 |
| 环绕（Arc/Orbit） | 摄影机绕主体弧形运动 | 强调中心人物、制造仪式感 |
| 手持（Handheld） | 人工手持的自然晃动感 | 纪实感、紧张感、不稳定情绪 |
| POV（主观视角） | 模拟角色视线 | 代入角色视角、增强沉浸感 |
| 航拍（Drone/Aerial） | 无人机或直升机航拍 | 宏大场景、全景过渡、上帝视角 |
| 轨道运镜（Track Dolly） | 轨道车平稳推进/平移 | 平滑运镜需求、专业级画面 |
| 摇臂（Jib/Crane） | 摇臂大范围升降+平移 | 大型场景调度、舞台感 |
| 斯坦尼康（Steadicam） | 稳定器随身跟拍 | 长镜头无缝跟拍、穿梭空间 |
| dolly zoom（滑动变焦） | 推拉+变焦同步，背景变形 | 悬疑感、眩晕感、内心崩溃 |
| 希区柯克式变焦 | 同dolly zoom | 同上，强调震惊/启示时刻 |
| 甩镜头（Whip Pan） | 快速横向急甩 | 快节奏转场、混乱感 |
| 可穿戴运动相机 | 绑在演员身上的小型相机 | 极限运动、第一人称动作 |
| 伸缩炮（Technocrane） | 大型伸缩臂+遥控头 | 复杂三维空间调度 |

#### 景别

| 景别 | 画面范围 | 叙事功能 |
|------|---------|---------|
| 极远景（Extreme Long Shot） | 人物在画面中极小，以环境为主 | 建立宏大空间感、史诗开篇 |
| 远景（Long Shot） | 人物全身，环境占主导 | 交代人物与环境关系 |
| 全景（Full Shot） | 人物全身充满画框 | 展示人物整体姿态、服装、走位 |
| 中全景（Medium Long Shot） | 膝盖以上 | 兼顾人物动作与环境关系 |
| 中景（Medium Shot） | 腰部以上 | 对话场景基础景别，兼顾表情与手势 |
| 中近景（Medium Close-Up） | 胸部以上 | 专注面部表情与台词 |
| 近景（Close-Up） | 肩部以上 | 强调情绪、台词、微表情 |
| 特写（Extreme Close-Up） | 局部细节（眼/嘴/手/道具） | 强调关键信息、情感爆发点 |
| 大特写（Macro） | 极细微细节（瞳孔/指纹） | 极度放大情绪、抽象化表达 |
| 微距（Macro Shot） | 极小物体全屏 | 产品或细节强调 |

#### 摄影角度

| 角度 | 描述 | 情绪/功能 |
|------|------|----------|
| 平拍（Eye Level） | 摄影机与人物视线齐平 | 中性客观、代入感 |
| 俯拍（High Angle） | 摄影机高于人物视线 | 人物显弱小、被控制、弱势 |
| 仰拍（Low Angle） | 摄影机低于人物视线 | 人物显高大、权威、压迫感 |
| 过肩（Over-the-Shoulder） | 越过一人肩膀拍另一人 | 对话关系、建立空间位置 |
| 正面（Frontal） | 正对人物面部 | 直面观众、打破第四面墙 |
| 侧面（Profile） | 90度侧对人物 | 孤独感、旁观感、轮廓强调 |
| 侧面45度（Three-Quarter） | 介于正面与侧面之间 | 自然生动的对话角度 |
| 背面（Over-the-Back） | 从人物背后拍摄 | 跟随视角、神秘感 |
| 顶拍（Top Shot/Bird's Eye） | 正上方垂直俯拍 | 上帝视角、抽象构图 |
| 底拍（Ground Level） | 贴地仰拍 | 特殊视效、压迫感 |
| 主观视角（POV） | 模拟角色看到的内容 | 沉浸式代入 |
| 荷兰角（Dutch Angle） | 摄影机倾斜 | 不安、混乱、失衡感 |

| 光位 | 说明 | 效果 |

| 侧光（Side Light） | 从侧面照射 | 强调纹理、增加戏剧性 |
| 顶光（Top Light） | 从上方照射 | 压抑感、审讯氛围 |

#### 氛围基调

| 氛围 | 说明 | 常用手法 |

#### 转场

| 转场方式 | 效果 | 用法 |
|---------|------|------|
| 切（Cut） | 瞬间切换 | 最基础转场，节奏连贯 |
| 叠化（Dissolve） | 前镜淡出后镜淡入重叠 | 时间流逝、温柔过渡 |
| 淡入（Fade In） | 从黑场逐渐显现 | 场景开始 |
| 淡出（Fade Out） | 逐渐隐入黑场 | 场景结束 |
| 划像（Wipe） | 一条线扫过切换画面 | 蒙太奇、快速场景更替 |
| 闪白（Flash/White Flash） | 瞬间白场过渡 | 时间跳跃、冲击感 |
| 闪黑（Black Flash） | 瞬间黑场过渡 | 断点、节奏停顿 |
| 匹配剪辑（Match Cut） | 前后画面形状/运动匹配 | 创意过渡、概念关联 |
| 跳跃剪辑（Jump Cut） | 同一主体时间跳跃 | 压缩时间、焦虑感 |
| L Cut | 前镜音频延续到后镜 | 平滑过渡、对话衔接 |
| J Cut | 后镜音频提前在前镜出现 | 预告下一场景情绪 |
