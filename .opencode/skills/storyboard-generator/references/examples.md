# 完整示例

> 本文档保留**详细模式**的完整填充示例（含剧本切割方案、分镜 JSON、拆分后组文件）。精简模式示例见 `phase-b-simplified.md`「示例」节（单组单镜 / 单组三镜）与「组{N}.md 文件格式」节，不再重复。

## 剧本切割方案

```
场/组切割方案:
  场1 (0-30s): 明朝龙江关码头
    组1 (0-15s): 龙江关码头全景 → 叙事功能: 建立大明海权盛世的空间格局
    组2 (15-30s): 郑和登船出发 → 叙事功能: 人物建立+启程仪式感
  场2 (30-45s): 时空穿梭·蒙太奇
    组1 (0-15s): 时空隧道与舰队更迭 → 叙事功能: 六百年海军演变蒙太奇
  共 2 场，3 组，总预估 45 秒
  注意：每组镜号独立从1开始，每组≤9镜头、≤15秒
```
