# 模型参数说明

## 支持模型

| 模型 | aspectRatio 格式 | imageSize | 说明 |
|---|---|---|---|
| `gpt-image-2-vip` | 像素格式 `"1024x1024"` | 不支持 | 支持 1K / 2K / 4K |
| `gpt-image-2` ★ | 像素格式 `"1024x1024"` | 不支持 | 仅支持 1K |
| `nano-banana-2` | 比例格式 `"1:1"` | `"1K"` / `"2K"` / `"4K"` | 额外支持 1:4、4:1、1:8、8:1 |
| `nano-banana-pro` | 比例格式 `"1:1"` | `"1K"` / `"2K"` / `"4K"` | — |
| `nano-banana-pro-vip` | 比例格式 `"1:1"` | `"1K"` / `"2K"` / `"4K"` | — |

脚本根据模型前缀自动选择参数格式：`gpt-image-*` 使用像素格式，`nano-banana-*` 使用比例格式 + imageSize。

## aspectRatio 像素映射（gpt-image 系列）

gpt-image 系列模型使用像素格式（如 `"1024x1024"`），脚本自动将比例格式（如 `"16:9"`）+ 图像尺寸（如 `"4K"`）转换为像素格式。

| 比例 | 1K | 2K | 4K |
|---|---|---|---|
| 1:1 | 1024x1024 | 2048x2048 | 2880x2880 |
| 16:9 | 1774x887 | 2048x1152 | 3840x2160 |
| 9:16 | 887x1774 | 1152x2048 | 2160x3840 |
| 3:2 | 1536x1024 | 2048x1360 | 3504x2336 |
| 2:3 | 1024x1536 | 1360x2048 | 2336x3504 |
| 4:3 | 1365x1024 | 2048x1536 | 2880x2160 |
| 3:4 | 1024x1365 | 1536x2048 | 2160x2880 |
| 21:9 | — | 2048x880 | 3840x1648 |
| 9:21 | — | 880x2048 | 1648x3840 |
| 1:3 | 688x2048 | — | 1280x3840 |
| 3:1 | 2048x688 | — | 3840x1280 |
| 2:1 | 2048x1024 | — | 3840x1920 |
| 1:2 | 1024x2048 | — | 1920x3840 |

> 仅 `gpt-image-2-vip` 支持 2K、4K 尺寸。`gpt-image-2` 仅支持 1K。

## aspectRatio 比例格式（nano-banana 系列）

nano-banana 系列模型直接使用比例格式，通过 `imageSize` 字段指定分辨率。

支持比例：`auto`、`1:1`、`16:9`、`9:16`、`4:3`、`3:4`、`3:2`、`2:3`、`5:4`、`4:5`、`21:9`

nano-banana-2 系列额外支持：`1:4`、`4:1`、`1:8`、`8:1`
