# 场景参考生成 Skill

生成场景参考图任务 JSON，由 Art-director 执行生图。

**设计原则**：所有智能决策由你（Agent）完成——读取文件、理解设定、构建 Prompt、组装任务表。Python 脚本仅做无状态的 Schema 校验。

## 路径约定

所有项目文件位于 `project/{项目名}/` 下：

```
project/{项目名}/
├── 全局依赖/
│   ├── 角色设定/角色设定.md
│   ├── 场景设定/场景设定.md              ← 入口索引
│   ├── 场景设定/具体设定/{场景名}.md      ← 独立场景文件
│   ├── 道具设定/道具设定.md
│   ├── 场景参考图/{场景名}_基准.png       ← 全局基准资产（产出物）
│   ├── 角色参考图/{角色名}_基准.png
│   └── 道具参考图/
├── 前期采样/
│   ├── 场景/{场景名}*.png               ← 场景采样图（可选，若有则严格遵循）
│   └── 风格/*.png                       ← 风格参考图
└── 原始剧本.md
```

## 输出 Schema

产出 `场景参考图_任务表.json` 必须符合 `.opencode/schemas/image-generation.json` 定义。核心字段：

| 字段 | 类型 | 固定值 | 说明 |
|------|------|--------|------|
| `prompt` | string | — | 生图提示词（必填）。**禁止描述剧情角色**（如郑和、一岛等），仅聚焦场景空间环境 |
| `model` | string | `"gpt-image-2"` | 固定为 gpt-image-2，不可变 |
| `imageSize` | string | `"1K"` | 固定为 1K，不可变 |
| `aspectRatio` | string | `"2:1"` | 固定为 2:1，不可变 |
| `filename` | string | — | 输出文件名，以 .png 结尾 |
| `images` | string[] | — | 参考图路径列表 |

## 定位模式

| 模式 | 触发阶段 | 核心输入 | 布局 | 输出路径 |
|------|---------|---------|------|---------|
| 全局基础参考 | Phase 2 — 全局视觉资产生成 | 场景设定 + 风格采样 | 左俯瞰+右三宫格 | `全局依赖/场景参考图/场景参考图_任务表.json` |

## 入口

- 共享定义（Prompt 模板、参数表、校验规则）：`rules/common.md`
- 全局级场景参考生成规则：`rules/global.md`
