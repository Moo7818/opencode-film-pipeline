# 场景参考生成 Skill

生成场景参考图任务 JSON，由 Art-director 执行生图。

支持三种工作模式：

- **全景模式（全局/Phase 2）**：基于全局设定（场景设定 + 风格采样 + 前期采样）生成本项目所有场景的基础参考图任务表，产出的 `{场景名}_基准.png` 作为后续 episode 模式的基准资产。左俯瞰+右二宫格复合排版，2:1 超宽横向构图。
- **Episode 模式（Phase 3）**：基于全局场景参考图（`{场景名}_基准.png`）+ 本集分镜脚本中的场景变化描述，生成本集场景参考图任务表，体现该集特有的场景状态变化（如时间推移、天气变化、破坏痕迹、临时陈设等）。
- **双视图模式**：基于全局场景设定，为每个场景生成 2 张独立单帧参考图——内景参考（`{场景名}_内景.png`）+ 外景参考（`{场景名}_外景.png`）。采用英文控制层+中文内容层双语 Prompt 结构（参考分镜 skill 视觉锚点图模板），16:9 电影画幅，4K 分辨率。

**设计原则**：所有智能决策由你（Agent）完成——读取文件、理解设定、构建 Prompt、组装任务表。Python 脚本仅做无状态的 Schema 校验。

## 路径约定

所有项目文件位于 `project/{项目名}/` 下：

```
project/{项目名}/
├── 全局依赖/
│   ├── 角色设定/角色设定.md
│   ├── 场景设定/场景设定.md              ← 入口索引
│   ├── 场景设定/具体设定/{场景名}.md      ← 独立场景文件
│   ├── 场景设定/场景参考图/{场景名}_基准.png ← 全局基准资产（Phase 2 产出，Phase 3 输入）
│   ├── 角色设定/角色设定.md
│   ├── 角色设定/角色参考图/{角色名}_基准.png
│   ├── 道具设定/道具设定.md
│   └── 道具设定/道具参考图/
├── {剧集号}/                              ← Episode 模式工作目录
│   ├── 分镜/分镜脚本.json                 ← 场景变化描述来源
│   ├── 场景参考图/{场景名}_{剧集号}.png    ← Episode 模式产出（由 art-director 生成）
│   └── 场景参考图_任务表.json             ← Episode 模式产出（任务表）
├── 前期采样/
│   ├── 场景/{场景名}*.png               ← 场景采样图（可选，若有则严格遵循）
│   └── 风格/*.png                       ← 风格参考图
└── 原始剧本.md
```

## 输出 Schema

产出 `场景参考图_任务表.json` 必须符合 `.opencode/schemas/image-generation.json` 定义。核心字段：

| 字段 | 类型 | 全景/Episode 固定值 | 双视图固定值 | 说明 |
|------|------|---------------------|-------------|------|
| `prompt` | string | — | — | 生图提示词（必填）。**禁止描述剧情角色**，仅聚焦场景空间环境 |
| `model` | string | `"gpt-image-2"` | `"gpt-image-2-vip"` | 模型名称 |
| `imageSize` | string | `"1K"` | `"4K"` | 分辨率 |
| `aspectRatio` | string | `"2:1"` | `"16:9"` | 画面比例 |
| `filename` | string | — | — | 输出文件名，以 .png 结尾 |
| `images` | string[] | — | — | 参考图路径列表 |

## 定位模式

| 模式 | 触发阶段 | 核心输入 | 布局 | 输出路径 |
|------|---------|---------|------|---------|
| 全景模式（Phase 2） | 全局视觉资产生成（global_character_tasks ~ global_scene_art） | 场景设定 + 风格采样 | 左俯瞰+右二宫格 | `全局依赖/场景设定/场景参考图/场景参考图_任务表.json` |
| Episode 模式（Phase 3） | 剧集级参考图（episode_scene_ref） | 全局场景参考图（基准资产）+ 本集分镜脚本中场景变化描述 | 左俯瞰+右二宫格（基于全局基准 + 本集变化） | `{剧集号}/场景参考图_任务表.json` |
| 双视图模式 | 全局视觉资产生成（global_scene_tasks） | 场景设定 + 风格采样 + 前期采样 | 独立单帧（内景 + 外景各 1 张） | `全局依赖/场景设定/场景参考图/场景参考图_任务表.json` |

### 模式职责边界

- **全景模式**：为每个场景生成 1 张基准参考图（左俯瞰+右二宫格复合排版），作为项目级统一资产。基准资产固化场景的空间布局、建筑风格、色调色温等"恒定属性"。
- **Episode 模式**：仅在本集分镜脚本对场景有"变化描述"时才生成任务表条目。变化描述指本集特有的临时状态，如"夜雨"、"战后残骸"、"节庆装饰"。基准资产未涉及的本集新增场景（如分镜新引入的过渡场景）也归 episode 模式处理。
- **双视图模式**：为每个场景生成 2 张独立单帧参考图（内景 + 外景），聚焦氛围质感和空间纵深。采用双语 Prompt（英文控制层 + 中文内容层），16:9 电影画幅，4K 分辨率。与全景模式互补，可并存。

> Episode 模式不重新定义场景的恒定属性——这些由全景基准资产约束。Episode 模式只叠加本集变化层。
