# 场景参考生成 Skill

生成场景参考图任务 JSON，由 Art-director 执行生图。

支持两种工作模式：

- **双视图模式（默认）**：基于全局设定（场景设定 + 风格采样 + 前期采样）为每个场景生成 2 张独立超宽全景参考图——内景参考（`{场景名}_内景.png`）+ 外景参考（`{场景名}_外景.png`）。采用英文控制层+中文内容层双语 Prompt 结构（参考分镜 skill 视觉锚点图模板），4:1 超宽全景画幅，4K 分辨率，nano-banana-2 模型。
- **备选全景模式**：基于全局设定生成左俯瞰+右二宫格复合排版场景参考图，gpt-image-2 / 1K / 2:1。产出的 `{场景名}_基准.png` 作为后续 episode 模式的基准资产。当项目需要俯瞰空间布局时使用。
- **Episode 模式**：基于全局双视图基准资产（`{场景名}_内景.png` + `{场景名}_外景.png`）+ 本集分镜脚本中的场景变化描述，生成本集场景参考图任务表，体现该集特有的场景状态变化（如时间推移、天气变化、破坏痕迹、临时陈设等）。

**设计原则**：所有智能决策由你（Agent）完成——读取文件、理解设定、构建 Prompt、组装任务表。Python 脚本仅做无状态的 Schema 校验。

## 路径约定

所有项目文件位于 `project/{项目名}/` 下：

```
project/{项目名}/
├── 全局依赖/

│   ├── 场景设定/场景设定.md              ← 入口索引
│   ├── 场景设定/具体设定/{场景名}.md      ← 独立场景文件
│   ├── 场景设定/场景参考图/{场景名}_内景.png ← 全局内景基准资产（Phase 2 产出，Phase 3 输入）
│   ├── 场景设定/场景参考图/{场景名}_外景.png ← 全局外景基准资产（Phase 2 产出，Phase 3 输入）
│   ├── 角色设定/角色设定.md
│   ├── 角色设定/角色参考图/{角色名}_基准.png
│   ├── 道具设定/道具设定.md
│   └── 道具设定/道具参考图/
├── {剧集号}/                              ← Episode 模式工作目录
│   ├── 分镜/分镜脚本.json                 ← 场景变化描述来源
│   ├── 场景参考图/{场景名}_内景_{剧集号}.png ← Episode 模式产出（由 art-director 生成）
│   ├── 场景参考图/{场景名}_外景_{剧集号}.png ← Episode 模式产出（由 art-director 生成）
│   └── 场景参考图_任务表.json             ← Episode 模式产出（任务表）
├── 前期采样/

```

## 输出 Schema

产出 `场景参考图_任务表.json` 必须符合 `.opencode/schemas/image-generation.json` 定义。核心字段：

| 字段 | 类型 | 双视图固定值（默认） | 备选全景固定值 | 说明 |
|------|------|---------------------|---------------|------|
| `prompt` | string | — | — | 生图提示词（必填）。**禁止描述剧情角色**，仅聚焦场景空间环境 |
| `model` | string | `"nano-banana-2"` | `"gpt-image-2"` | 模型名称 |
| `imageSize` | string | `"4K"` | `"1K"` | 分辨率 |
| `aspectRatio` | string | `"4:1"` | `"2:1"` | 画面比例 |
| `filename` | string | — | — | 输出文件名，以 .png 结尾 |
| `images` | string[] | — | — | 参考图路径列表 |

## 定位模式

| 模式 | 触发阶段 | 核心输入 | 布局 | 输出路径 |
|------|---------|---------|------|---------|
| 双视图模式（默认） | 全局视觉资产生成（global_scene_tasks） | 场景设定 + 风格采样 + 前期采样 | 独立超宽全景单帧（内景 + 外景各 1 张） | `全局依赖/场景设定/场景参考图/场景参考图_任务表.json` |
| 备选全景模式 | 全局视觉资产生成（global_scene_tasks） | 场景设定 + 风格采样 | 左俯瞰+右二宫格 | `全局依赖/场景设定/场景参考图/场景参考图_任务表.json` |
| Episode 模式（Phase 3） | 剧集级参考图（episode_scene_ref） | 双视图基准资产 + 本集分镜脚本中场景变化描述 | 独立超宽全景单帧（内景 + 外景各 1 张 + episode 变化） | `{剧集号}/场景参考图_任务表.json` |

### 模式职责边界

- **双视图模式（默认）**：为每个场景生成 2 张独立超宽全景参考图（内景 + 外景），聚焦氛围质感和空间纵深。采用双语 Prompt（英文控制层 + 中文内容层），4:1 超宽全景画幅，4K 分辨率，nano-banana-2 模型。
- **备选全景模式**：为每个场景生成 1 张基准参考图（左俯瞰+右二宫格复合排版），作为项目级统一资产。当项目需要俯瞰空间布局总览时使用。基准资产固化场景的空间布局、建筑风格、色调色温等"恒定属性"。
- **Episode 模式**：仅在本集分镜脚本对场景有"变化描述"时才生成任务表条目。变化描述指本集特有的临时状态，如"夜雨"、"战后残骸"、"节庆装饰"。基准资产未涉及的本集新增场景也归 episode 模式处理。

> Episode 模式不重新定义场景的恒定属性——这些由全局基准资产约束。Episode 模式只叠加本集变化层。

## 入口

- 共享定义（Prompt 模板、参数表、校验规则）：`rules/common.md`（双视图默认）
- 备选全景模式模板：`rules/common_panoramic.md`（左俯瞰+右二宫格，gpt-image-2/1K/2:1）
- 全局级场景参考生成规则：`rules/global.md`
- 剧集级场景参考生成规则：`rules/episode.md`
