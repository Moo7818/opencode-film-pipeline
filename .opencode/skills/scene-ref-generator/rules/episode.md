# 剧集级参考流程

> 共享定义（Prompt 模板、参数表、校验规则）见 `rules/common.md`。
> 本模式**只产出任务表 JSON**，不直接生成图片——生图由 Art-director Agent 执行。

## 触发条件

- 阶段：剧集级参考图（episode_scene_ref）
- 输入：project_config.json + 全局场景参考图（基准资产）+ 全局场景设定文件 + 本集分镜脚本
- 输出：`project/{项目名}/{剧集号}/场景参考图_任务表.json`

## 核心职责

Episode 模式负责将"全局场景基准 + 本集场景变化"组装为任务表 JSON，供 Art-director 执行生图。Agent 的核心工作是：

1. 读取全局场景设定与 project_config.json，确定场景清单
2. 读取本集分镜脚本，提取每个场景在本集的变化描述
3. 仅对**有变化描述**的场景生成 task；无变化的场景不进入任务表（art-director 直接复用全局基准资产即可）
4. 对每个 task，以全局基准资产为视觉一致性锚点，将本集变化叠加进 prompt
5. 输出任务表 JSON

> **重要约束**：Episode 模式不重新定义场景的恒定属性（空间布局、建筑风格、色调色温等）。这些由全局基准资产约束。Episode 模式只叠加本集变化层（如时间推移、天气变化、破坏痕迹、临时陈设等）。

## 步骤 1：收集输入文件

| 文件 | 用途 |
|------|------|
| `.meta/projects/{uuid}/project_config.json` | 项目参数（项目名、剧集号、视觉风格配置等） |
| `project/{项目名}/全局依赖/全局设定.md` | 画风参考、色调色温、视觉语言标准（提取 `{style_desc}`） |
| `project/{项目名}/全局依赖/场景设定/场景设定.md` | 场景索引清单 |
| `project/{项目名}/全局依赖/场景设定/具体设定/{场景名}.md` | 各场景的详细设定（用于构建 prompt 的恒定属性部分） |
| `project/{项目名}/全局依赖/场景设定/场景参考图/{场景名}_基准.png` | **全局基准资产**（Phase 2 产出，本阶段核心输入） |
| `project/{项目名}/{剧集号}/分镜/分镜脚本.json` | 提取本集场景变化描述 |
| `project/{项目名}/前期采样/风格/*.png` | 风格参考图（所有 task 共用） |

> **前置依赖**：episode 模式必须在 global_scene_art 阶段完成后执行，即全局基准资产 `{场景名}_基准.png` 必须已存在。若某场景的全局基准资产缺失，应报告给 orchestrator 并跳过该场景的 task 生成。

## 步骤 2：确定场景清单

1. 读取 `project_config.json`，获取项目名与当前剧集号
2. 读取 `场景设定/场景设定.md` 的场景清单表，列出所有场景名
3. 对每个场景，确认 `全局依赖/场景设定/场景参考图/{场景名}_基准.png` 存在；缺失则跳过并报告

> 场景清单是 episode 模式的搜索范围——只有出现在全局场景清单中的场景才会被处理。分镜脚本中新引入的过渡场景（全局清单中不存在）需先由 orchestrator 决定是否扩展全局场景清单，再进入 episode 模式。

## 步骤 3：提取本集场景变化描述

读取 `project/{项目名}/{剧集号}/分镜/分镜脚本.json`，对每个场景在本集出现的内容进行扫描，提取变化描述。

### 提取规则

1. 逐场扫描分镜脚本的「通用设定」与「场景描述」字段
2. 查找场景在本集特有的状态变化（与全局设定对比）
3. 同一场景在本集多场出现时，合并所有变化描述（按场次顺序去重）
4. 若场景在本集出场但**无变化描述**，不进入任务表（直接复用全局基准资产）

### 变化类型识别

| 变化类型 | 是否生成 task | 示例 |
|---------|--------------|------|
| **时间/光照变化** | ✅ 生成 | 晴日→夜雨、白昼→黄昏、清晨→午夜 |
| **天气/季节变化** | ✅ 生成 | 晴→暴雨、夏→冬雪、晨雾→晴空 |
| **场景破坏/损毁** | ✅ 生成 | 战后残骸、火灾后废墟、墙体坍塌 |
| **临时陈设/装饰** | ✅ 生成 | 节庆装饰、宴会场、临时帐篷、祭坛 |
| **关键道具入景** | ✅ 生成 | 巨型战车占据广场、旗帜插满城墙 |
| **场景功能临时转换** | ✅ 生成 | 朝堂→宴会厅、卧房→临时病房 |
| **光影氛围变化** | ✅ 生成 | 烛光→月光、室内→火光摇曳 |
| **无变化** | ❌ 不生成 | 场景状态与全局基准一致 |

### 提取结果示例

```
场景「长江江边」 → 第2场: 夜雨笼罩，江面波涛汹涌，雷光照亮天际
场景「皇宫正殿」 → 第5场: 朝堂改为宴会陈设，悬挂红灯笼，铺设红毯
场景「将军府卧房」 → 无变化描述 → 不进入任务表
```

> **重要**：本集变化描述需具体、可视觉化，避免抽象描述（如"气氛紧张"）。Agent 应将抽象表述转化为可生图的视觉元素（如"光线昏暗，烛火摇曳，阴影拉长"）。

## 步骤 4：构建 Prompt

### 步骤 4a：模式判断

Episode 模式下，全局基准资产**始终存在**且**必须作为 images[0]**。是否额外引入前期采样图作为辅助参考，按以下判断：

| 模式 | 条件 | string0（一致性引导词） | 参考图 |
|------|------|------------------------|--------|
| **Episode 模式 A** | `前期采样/场景/{场景名}*.png` 存在 | `"场景构图、空间布局、建筑风格与色调色温严格遵循参考图片1（全局基准资产），本集变化层叠加于其上"` | 全局基准资产（images[0]）+ 场景采样图（images[1]，辅助）+ 风格参考图 |
| **Episode 模式 B** | `前期采样/场景/{场景名}*.png` 不存在 | `"场景构图、空间布局、建筑风格与色调色温严格遵循参考图片1（全局基准资产），本集变化层叠加于其上"` | 全局基准资产（images[0]）+ 风格参考图 |

> **关键约束**：Episode 模式下 string0 **始终固定为上述语句**，因为视觉一致性基准永远是全局基准资产（不是采样图）。前期采样图仅作为辅助参考，不替代全局基准资产的地位。

### 步骤 4b：提取视觉风格

按 `rules/common.md` 的「视觉风格提取」规则，从 `project/{项目名}/全局依赖/全局设定.md` 中提取视觉风格关键字，记为 `{style_desc}`。

> **无全局设定时**：从 `前期采样/风格/` 中的参考图文件名判断风格倾向，仍无法判断时使用默认值"超写实影视级画面"。

### 步骤 4c：Prompt 模板

Prompt 在 `rules/common.md` 的全局模板基础上，**末尾追加本集变化层**：

```
{string0}，
生成一张实景环境空间展示图，左边为一张1:1比例的空间垂直俯瞰（展示大约400平米空间即可，在左上角标明北向，在图中用箭头标记角色所在位置箭头方向为角色面向的方向，不加入文字标注），右侧为2行1列等比的二宫格（第一行：从正面拍摄角色所在位置的120°超广角视图，第二行：从反面拍摄角色所在位置的120°超广角视图，严格保证各个视图都是对该空间整体的一致性还原，严禁出现任何非群众角色），每张图左上角用英文小字标明各视图的名称。
{style_desc}，{string1}，1K分辨率，极致细节，照片级真实质感，镜头语言{string2}。
{string3}，
{string4}，
{string5}，
{string6}，
{string7}，
{string8}.
本集场景变化：{episode_changes}.
```

### 步骤 4d：参数说明

| 参数 | 含义 | Episode 模式取值规则 |
|------|------|---------------------|
| style_desc | 视觉风格 | 按步骤 4b 提取，与全局模式一致 |
| string0 | 一致性引导词 | **固定为** `"场景构图、空间布局、建筑风格与色调色温严格遵循参考图片1（全局基准资产），本集变化层叠加于其上"` |
| string1 | 时代/风格标识 | 从全局场景设定提取，与 global 模式一致（如"明朝东方古典建筑与江景"） |
| string2 | 镜头语言 | 固定值 `"焦点精准、场景纵深强烈"` |
| string3 | 空间整体（本集版） | 全局空间描述 + 本集空间变化（如"夜雨笼罩的长江江面，波涛汹涌"），≥80字 |
| string4 | 核心特征（本集版） | 全局核心特征 + 本集临时陈设/破坏痕迹，≥60字 |
| string5 | 氛围/基调（本集版） | 本集氛围（如"暴雨夜的肃杀与压抑"），≥40字 |
| string6 | 光线与色彩（本集版） | 本集光线（如"夜雨笼罩，偶有雷光照亮天际，江面反射冷白闪光"），≥60字 |
| string7 | 天气与氛围（本集版） | 本集天气与整体环境氛围，≥60字 |
| string8 | 整体质感 | 与 style_desc 风格一致 |
| episode_changes | 本集变化摘要 | **新增字段**。从分镜脚本提取的本集场景变化描述，简洁列出所有变化点（≤100字），便于人工审查与 orchestrator 决策 |

> **关键策略**：string3~string7 既包含全局恒定属性（来自全局场景设定），又叠加本集变化。Agent 应将本集变化**融入**对应字段，而非简单罗列。例如：
> - 错误：string3 = "长江江面宽达二三里"，episode_changes = "夜雨"
> - 正确：string3 = "夜雨笼罩下的长江江面，江面宽达二三里，波涛汹涌，能见度降低"

### 步骤 4e：negative_prompt 构建

为每个 task 构建反向提示词，避免常见的视觉错误。negative_prompt 应包含：

- 全局通用反向词：`"剧情角色特写, 文字水印, 低质量, 模糊, 变形, 多余手指"`
- 本集专属反向词：根据本集变化反向推导。例如本集为"夜雨"场景，negative_prompt 应包含 `"强光直射, 晴空, 白昼光线"`

## 步骤 5：生成任务表 JSON

```json
{
  "model": "gpt-image-2",
  "episode": "{剧集号}",
  "tasks": [
    {
      "scene_name": "{场景名}",
      "episode_specific_changes": "从分镜脚本提取的本集场景变化描述，简洁列出所有变化点",
      "global_base_image": "project/{项目名}/全局依赖/场景设定/场景参考图/{场景名}_基准.png",
      "prompt": "场景构图、空间布局、建筑风格与色调色温严格遵循参考图片1（全局基准资产），本集变化层叠加于其上，\n生成一张实景环境空间展示图，左边为一张1:1比例的空间垂直俯瞰……{style_desc}，{string1}，1K分辨率，极致细节，照片级真实质感，镜头语言{string2}。\n{string3}，\n{string4}，\n{string5}，\n{string6}，\n{string7}，\n{string8}.\n本集场景变化：{episode_changes}.",
      "negative_prompt": "剧情角色特写, 文字水印, 低质量, 模糊, 变形, 多余手指, {本集专属反向词}",
      "imageSize": "1K",
      "aspectRatio": "2:1",
      "filename": "{场景名}_{剧集号}.png",
      "images": [
        "project/{项目名}/全局依赖/场景设定/场景参考图/{场景名}_基准.png",
        "project/{项目名}/前期采样/风格/{风格文件}.png"
      ]
    }
  ],
  "output_path": "project/{项目名}/{剧集号}/场景参考图/"
}
```

### 任务表字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `scene_name` | string | 场景名（与全局场景设定中的场景名一致） |
| `episode_specific_changes` | string | 本集场景变化描述，从分镜脚本提取，用于人工审查与 orchestrator 决策 |
| `global_base_image` | string | 全局基准资产路径（与 `images[0]` 值相同），便于人工追踪 |
| `prompt` | string | 生图提示词，结合全局设定 + 本集变化 |
| `negative_prompt` | string | 反向提示词，避免视觉错误 |
| `output_path` | string（顶层） | 输出目录，所有 task 共享：`project/{项目名}/{剧集号}/场景参考图/` |
| `filename` | string | 输出文件名：`{场景名}_{剧集号}.png`，完整输出路径 = `output_path + filename` |
| `images` | string[] | 参考图路径列表，`images[0]` **必须**为全局基准资产 |

> **扩展字段说明**：`scene_name`、`episode_specific_changes`、`global_base_image`、`negative_prompt` 为 Episode 模式扩展字段，供人工审查与 orchestrator 决策使用。Art-director 执行生图时使用 `prompt`、`imageSize`、`aspectRatio`、`filename`、`images` 字段，扩展字段不影响生图流程。

**自检清单：**
- □ 仅有变化描述的场景才生成 task，无变化的场景不进入任务表
- □ 每个 task 的 `images[0]` 为全局基准资产（`{场景名}_基准.png`），且与 `global_base_image` 字段值一致
- □ `filename` 格式为 `{场景名}_{剧集号}.png`
- □ `output_path` 为 `project/{项目名}/{剧集号}/场景参考图/`
- □ `prompt` 包含"左边为一张1:1比例的空间垂直俯瞰"布局描述
- □ `prompt` 包含"右侧为2行1列等比的二宫格"布局描述
- □ `prompt` 包含"120°超广角视图"视角描述
- □ `prompt` 包含"左上角用英文小字标明各视图的名称"标注要求
- □ `prompt` 末尾包含 `本集场景变化：{episode_changes}.` 段落
- □ `prompt` 禁止出现剧情角色描述（如郑和、一岛等人物外观、服饰、动作）
- □ `string0` 固定为"场景构图、空间布局、建筑风格与色调色温严格遵循参考图片1（全局基准资产），本集变化层叠加于其上"
- □ `style_desc` 已从全局设定提取，非硬编码
- □ `episode_specific_changes` 字段已填写本集变化摘要，简洁可读
- □ `negative_prompt` 包含全局通用反向词 + 本集专属反向词
- □ `images` 数组不包含角色参考图或道具参考图
- □ `aspectRatio` 固定为 `2:1`，`imageSize` 固定为 `1K`，`model` 固定为 `gpt-image-2`

## 步骤 6：Schema 校验

1. `validate_top_level(data)` 校验顶层字段（`model`、`output_path`、`tasks`）
2. `validate_tasks(tasks, "episode")` 校验任务列表

> Episode 模式扩展字段（`scene_name`、`episode_specific_changes`、`global_base_image`、`negative_prompt`）不参与 schema 严格校验，但 Agent 应确保字段非空且语义合理。

两个函数均返回空列表则通过。

## 步骤 7：输出完成提示

```
剧集 {剧集号} 场景参考图任务表已生成，等待 Art-director 执行生图
- {N} 个场景有本集变化，已生成 {N} 个 task
- {M} 个场景无变化，将直接复用全局基准资产
```

## 参考图上传顺序

### Episode 模式 A（有场景采样图）

| 位置 | 内容 |
|------|------|
| images[0] | **全局基准资产**（`全局依赖/场景设定/场景参考图/{场景名}_基准.png`） |
| images[1] | 场景采样图（`前期采样/场景/{场景名}*.png`，辅助参考） |
| images[2] | 风格参考图（`前期采样/风格/*.png`） |

### Episode 模式 B（无场景采样图）

| 位置 | 内容 |
|------|------|
| images[0] | **全局基准资产**（`全局依赖/场景设定/场景参考图/{场景名}_基准.png`） |
| images[1] | 风格参考图（`前期采样/风格/*.png`） |

**绝对禁止**加入角色参考图（`角色设定/角色参考图/`）或道具参考图（`道具设定/道具参考图/`）下的任何文件。

## 差异对比

| 维度 | 全局模式（Phase 2） | Episode 模式（Phase 3，本文件） |
|------|--------------------|------------------------------|
| 触发阶段 | 全局视觉资产生成（global_character_tasks ~ global_scene_art） | 剧集级参考图（episode_scene_ref） |
| 核心输入 | 场景设定 + 风格采样 + 前期采样 | 全局基准资产 + 本集分镜脚本中场景变化描述 |
| 任务数量 | 每个场景 1 个 task（task 数 = 场景数） | 仅有变化描述的场景生成 task（task 数 ≤ 场景数） |
| images[0] | 场景采样图（模式 A）或风格参考图（模式 B） | **全局基准资产**（始终） |
| string0 | 模式 A/B 不同，按场景采样图存在与否切换 | 固定为"严格遵循参考图片1（全局基准资产），本集变化层叠加于其上" |
| prompt 末尾 | 无本集变化段落 | 追加 `本集场景变化：{episode_changes}.` 段落 |
| 扩展字段 | 无 | `scene_name`、`episode_specific_changes`、`global_base_image`、`negative_prompt` |
| 输出路径 | `全局依赖/场景设定/场景参考图/场景参考图_任务表.json` | `{剧集号}/场景参考图_任务表.json` |
| 输出文件名 | `{场景名}_基准.png` | `{场景名}_{剧集号}.png` |
| 是否直接生图 | 否（由 art-director 执行） | 否（由 art-director 执行） |
