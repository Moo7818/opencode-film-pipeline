# 全局基础参考流程

> 共享定义（Prompt 模板、参数表、校验规则）见 `rules/common.md`。

## 触发条件

- 阶段：全局视觉资产生成（global_character_tasks ~ global_scene_art）
- 输入：全局设定 + 场景设定 + 前期采样（场景/风格）

## 执行步骤

### 步骤 1：收集输入文件

| 文件 | 用途 |
|------|------|
| `project/{项目名}/全局依赖/全局设定.md` | 画风参考、色调色温、视觉语言标准 |
| `project/{项目名}/全局依赖/场景设定/场景设定.md` | 场景索引清单 |
| `project/{项目名}/全局依赖/场景设定/具体设定/{场景名}.md` | 各场景的详细设定 |
| `project/{项目名}/前期采样/场景/{场景名}*.png` | 场景采样图（可选，决定是否作为参考图） |
| `project/{项目名}/前期采样/风格/*.png` | 风格参考图（所有场景共用） |

### 步骤 2：确定场景清单

从 `场景设定/场景设定.md` 的**场景清单**表中提取所有需要生成的场景。每个场景 1 个 task，**task 数量 = 场景数量**。

### 步骤 3：模式判断

对每个场景，检查 `前期采样/场景/` 下是否存在以该场景名命名的图片文件：

| 模式 | 条件 | string0（一致性引导词） | 参考图 |
|------|------|------------------------|--------|
| **模式 A** | `前期采样/场景/{场景名}*.png` 存在 | **写实风格**: `"场景构图与视觉风格严格遵循参考图片1-图片n"`; **非写实风格**: `"场景构图与空间布局严格遵循参考图片1-图片n"` | **场景采样图（必选，放images[0]）** + 风格参考图 |
| **模式 B** | `前期采样/场景/{场景名}*.png` 不存在 | `"视觉风格严格参考参考图片"` | 仅风格参考图 |

> **模式 A 关键约束**：string0 必须使用"严格遵循"语气（不可弱化为"参考"），与 images 中传入的参考图形成双重一致性约束。

### 步骤 3A：分析参考图特征（仅模式 A）

在写入 prompt 前，必须对场景采样图进行分析，提取视觉特征：

```
示例分析流程：
1. 文件名清单：[卧室-1.jpg, 卧室-2.jpg, 卧室-3.jpg]
2. 覆盖方位：正面全景、局部特写、不同角度
3. 核心视觉特征提取：
   · 空间风格：现代轻奢婚庆卧室
   · 色调色温：暖金色主调，温馨浪漫
   · 光线方向：柔和的自然窗光 + 暖色补光
   · 核心元素：大床、红色婚庆床品、水晶吊灯
   · 未覆盖视角：背面、左侧、右侧 → 基于正面布局合理推断
4. 将提取特征写入 string3~string7
```

> **风格适配**：非写实风格下，string0 中的"视觉风格"字样需替换为"空间布局"，因为视觉风格由全局 style_desc 控制，不继承自采样图。

### 步骤 4：提取视觉风格

按 `rules/common.md` 的「视觉风格提取」规则，从全局设定中提取 `{style_desc}`，用于 Prompt 模板中的风格描述。

### 步骤 5：构建 Prompt

使用 `rules/common.md` 的 **Prompt 模板**和**参数说明**逐字替换占位符（含 `{style_desc}`）。

**全局模式专属参数定义：**
- **style_desc**：按步骤 4 提取
- **string0**：按上方模式判断确定。**模式 A 必须根据风格类型选择：写实风格使用 `"场景构图与视觉风格严格遵循参考图片1-图片n"`，非写实风格使用 `"场景构图与空间布局严格遵循参考图片1-图片n"`，禁止弱化措辞**
- **string1~string8**：从各场景具体设定文件中提取。**注意：提取时跳过所有剧情角色描述（如郑和的服饰、一岛的着装等），仅提取场景空间/环境/建筑/光线等元素**

| 参数 | 字段来源 | 提取说明 |
|------|---------|---------|
| string1 | 基本信息.所属时代 + 场景名称 | 如"明朝东方古典建筑与江景" |
| string2 | 固定值 | `"焦点精准、场景纵深强烈"` |
| string3 | 空间整体 | 从"视觉描述"提取场景全貌——空间尺度、水域/地形、天际线，**模式 A 须与采样图空间布局一致**，≥80字 |
| string4 | 核心特征 | 从"视觉描述"提取核心建筑/主体的特征与细节，**模式 A 须与采样图主体风格一致**，≥60字 |
| string5 | 氛围/基调 | 从"氛围/基调"提取，≥40字 |
| string6 | 光线/色彩 | 从"光线/色彩要求"提取，**模式 A 须参考采样图中的实际光影方向/色温**，≥60字 |
| string7 | 天气 + 氛围 | 从"氛围/视觉描述"提取天气条件与整体环境氛围，**禁止套用前/中/远景的景别层次结构**，≥60字 |
| string8 | 整体质感 | 与 style_desc 风格一致的质感描述，如"影视级写实摄影，空气透视与颗粒质感" |

### 步骤 6：生成任务 JSON

```json
{
  "model": "gpt-image-2",
  "tasks": [
    {
      "prompt": "场景构图与视觉风格严格遵循参考图片1-图片n，\n生成一张实景环境空间展示图，左边为一张1:1比例的空间垂直俯瞰（展示大约400平米空间即可，在左上角标明北向，在图中用箭头标记角色所在位置箭头方向为角色面向的方向，不加入文字标注），右侧为3行1列等比的三宫格（第一行：从正面拍摄角色所在位置的120°超广角视图，第二行：从反面拍摄角色所在位置的120°超广角视图，第三行：3.1为从左侧拍摄角色所在位置的视图，3.2为从右侧拍摄角色所在位置的视图，严格保证各个视图都是对该空间整体的一致性还原，严禁出现任何非群众角色），每张图左上角用英文小字标明各视图的名称。\n影视级写实摄影，明朝东方古典建筑与江景，1K分辨率，极致细节，照片级真实质感，镜头语言焦点精准、场景纵深强烈。\n空间整体……",
      "imageSize": "1K",
      "aspectRatio": "2:1",
      "filename": "{场景名}_基准.png",
      "images": [
        "project/{项目名}/前期采样/场景/{场景名}.png",
        "project/{项目名}/前期采样/风格/{风格文件}.png"
      ]
    }
  ],
  "output_path": "project/{项目名}/全局依赖/场景设定/场景参考图/"
}
```

**自检清单：**
- □ tasks 数量等于场景数量
- □ style_desc 已从全局设定提取，非硬编码"概念图"
- □ 每个 task 的 prompt 严格遵循模板格式，前置布局引导文本必须出现在 string0 之后、style_desc 之前
- □ prompt 包含"左边为一张1:1比例的空间垂直俯瞰"布局描述
- □ prompt 包含"展示大约400平米空间"空间范围描述
- □ prompt 包含"右侧为3行1列等比的三宫格"布局描述
- □ prompt 包含"120°超广角视图"视角描述
- □ prompt 包含"左上角用英文小字标明各视图的名称"标注要求
- □ prompt 包含"在左上角标明北向"或"北向"的俯瞰标注
- □ prompt 包含"在图中用箭头标记角色所在位置"的角色标注
- □ **prompt 禁止出现剧情角色描述**（如郑和、一岛等人物外观、服饰、动作），仅聚焦场景空间环境
- □ **三宫格各视图描述中严格保证空间整体的一致性还原，严禁出现非群众角色**
- □ **string7 未套用前/中/远景景别层次结构**（如"远景...中景...近景..."）
- □ **不同场景的 prompt 描述存在差异化**，无重复的短语或句式（如"江面宽达二三里"仅出现在一个场景中）
- □ **images 数组中不包含角色参考图或道具参考图**，仅含场景采样图和/或风格参考图
- □ mode_A（场景采样图存在）：string0 使用"严格遵循"措辞，images[0] 为场景采样图，images[1] 为风格参考图
- □ mode_A string0 根据风格类型正确选择：写实用"场景构图与视觉风格"，非写实用"场景构图与空间布局"
- □ mode_B（场景采样图不存在）：images 已添加风格参考图
- □ 模式 A 已执行参考图分析，提取视觉特征已融入 string3~string7
- □ 场景名称匹配场景清单

### 步骤 7：Schema 校验

1. `validate_top_level(data)` 校验顶层字段
2. `validate_tasks(tasks)` 校验任务列表

两个函数均返回空列表则通过。

### 步骤 8：输出完成提示

使用 `rules/common.md` 中的完成提示。

## 参考图上传顺序

### 模式 A（有场景采样图）

| 位置 | 内容 |
|------|------|
| images[0] | 场景采样图（`前期采样/场景/{场景名}*.png`） |
| images[1] | 风格参考图（`前期采样/风格/*.png`） |

**绝对禁止**加入角色参考图（`角色设定/角色参考图/`）或道具参考图（`道具设定/道具参考图/`）下的任何文件。

### 模式 B（无场景采样图）

| 位置 | 内容 |
|------|------|
| images[0] | 风格参考图（`前期采样/风格/*.png`） |

**绝对禁止**加入角色参考图（`角色设定/角色参考图/`）或道具参考图（`道具设定/道具参考图/`）下的任何文件。
