# 共享定义

以下规范适用于全局基础参考模式。

## 参考图严格遵循原则

当 `前期采样/场景/{场景名}*.png` 参考图存在时，Agent **必须**严格遵守以下规则：

### 参考图的权威地位

| 层级 | 优先级 | 说明 |
|------|--------|------|
| **P0 — 强制遵守** | 最高 | 场景的空间布局、建筑风格、色调色温、环境基调，必须以采样图为**唯一基准**，不得偏离或自由发挥 |
| **P1 — 尽量跟随** | 高 | 采样的光影方向、天气条件、植被/水域特征、镜头构图，必须在 prompt 中声明"严格遵循参考图" |
| **P2 — 允许补充** | 中 | 参考图未覆盖的方位视角（如背面、右侧）可基于正面/左侧图合理推断 |
| **P3 — 可补充细节** | 低 | 仅参考图完全无法提供的视觉信息（如特定时间段的事件动作），可额外补充 |

### 参考图对 Prompt 各位置的约束

| prompt 位置 | 约束来源 | 约束规则 |
|-------------|---------|---------|
| string0（一致性引导词） | 场景采样图 | **必须**声明"严格遵循"语气 |
| string3（空间整体描述） | 场景采样图的全局环境 | 空间尺度、地形地貌、天际线的描述必须与参考图一致 |
| string4（核心特征） | 采样图中的主体建筑/场景 | 核心建筑/场景主体的样式、配色、结构须与参考图匹配 |
| string6（光线与色彩） | 采样图的光影 | 从参考图中提取色温、光线方向、对比度等具体特征 |
| images[] | 所有参考图 | **必须**列出所有可用的参考图路径，场景采样图在前，风格图在后 |

### 参考图分析步骤

在构建 prompt 之前，**必须**先执行以下分析：

```
1. 列出所有匹配的场景采样图文件（文件名、路径）
2. 根据文件名推断覆盖的方位/视角（如"卧室-1.jpg" → 卧室正面全景）
3. 确认采样图覆盖了多少方位（若仅有正面，需推断背面/侧面的布局）
4. 提取核心视觉特征：建筑风格、色调色温、空间尺度、光线方向
5. 将提取的特征融入 string3~string7 的描述
```

## 场景空间参考图布局约束

- 一个场景 = 一个 task。每个场景只生成 1 个 task，该 task 的 prompt 引导生图模型输出**左俯瞰 + 右三宫格**的复合排版。
- **左区**：一张 **1:1 比例**的空间垂直俯瞰图（覆盖约 **400 平米**范围），**左上角标明北向（N）**，**在图中用箭头标记角色所在位置（箭头方向为角色面向的方向），不加入文字标注**，展现场景的整体空间布局与建筑/地形俯视关系。
- **右区**：**3 行 1 列等比的三宫格**，各视图内容如下：
  - **第一行**：从**正面**拍摄角色所在位置的 **120° 超广角视图**
  - **第二行**：从**反面**拍摄角色所在位置的 **120° 超广角视图**
  - **第三行**：**3.1** 为从**左侧**拍摄角色所在位置的视图，**3.2** 为从**右侧**拍摄角色所在位置的视图
- **严格保证各个视图都是对该空间整体的一致性还原**，**严禁出现任何非群众角色的剧情人物**。
- 每张图**左上角用英文小字标明各视图的名称**（如 top-down、front 120°、back 120°、left、right 等）。
- **绝对禁止**为不同视角分别创建独立 task，也**禁止**只生成单张全景图或无排版结构的散图。
- **aspectRatio 必须固定为 2:1**（超宽横向构图才能容纳左俯瞰 + 右三宫格的排版，2:1 比 16:9 更宽，为三宫格提供更多横向空间）。
- Prompt 中**必须包含**用户指定的前置布局引导语（见 Prompt 模板），以及各视图的标注要求。

### 排版布局

```
┌───────────┬──────────────────────┐
│           │  Row1: Front 120°    │
│  左:俯瞰   ├──────────────────────┤
│  (1:1)    │  Row2: Back 120°     │
│  北向标注   ├──────────────────────┤
│  角色朝向   │ Row3: Left | Right   │
└───────────┴──────────────────────┘
```

不要逐一描述每个方格画面内的具体构图。应该：
1. 前置布局引导指令（固定文本，指定整体排版结构）
2. 描述场景整体的环境特征（空间尺度、建筑风格、环境基调）
3. 补充关键的细节要素（核心建筑、特殊结构、标志元素）
4. 模型会自行理解各方位的内容呈现

### 标注要求

- **左区俯瞰图**：左上角标注**北向（N）**，可用简易指北针或"顶视图"文字。**在图中用箭头标记角色所在位置（箭头方向为角色面向的方向），不加入文字标注**
- **右区三宫格**：每张图左上角用**英文小字**标明视图名称（front 120° / back 120° / left / right 等，根据场景需要选择最合适的标注）
- **样式**：简洁白底黑字或半透明底白字标签，不遮挡主体内容

**正确示例：**

## 单场景图文对应

全局依赖的 `场景设定/具体设定/` 下每个 `.md` 文件代表一个独立场景。全局基础参考阶段需要为每个场景生成 1 张场景参考图，因此 task 数量 = 具体设定中的场景数量。

| 场景设定文件 | 对应的 task 数 |
|-------------|--------|
| 每个 `.md` 文件 | 1 个 task |

## 缺省值原则（重要）

AI 图像模型对某些环境属性有统计偏见——如果 prompt 不明确声明，模型会按训练数据"自动填空"。**必须对每个可能被默认填充的视觉属性做显式声明**：若不存在则明确否定，若存在则具体描述。

关键防范列表（必需在 prompt 中显式声明的属性）：

| 属性 | 风险 | 正确做法 |
|------|------|---------|
| 视觉风格 | 默认输出概念图风格 | 从全局设定提取实际风格，如影视级写实摄影/卡通/3D渲染等 |
| 色调/色温 | 历史场景默认偏暗偏黄 | 按场景设定明确写暖金/冷白/清冷等 |
| 天气/光线 | 默认晴天正午 | 描述晨光/黄昏/阴雨/雾霭/风暴等 |
| 建筑风格 | 古代默认中式古典 | 具体描述建筑风格与历史时期 |
| 植被/环境 | 忽略季节/地域 | 描述植被、水域、地域环境 |
| 人群密度 | 空无一人或过度拥挤 | 按设定明确多少人或无人 |
| 剧情人物 | 默认引入角色人物 | **场景参考图严禁出现剧情角色（如郑和、一岛等）**。Prompt 中不得描述任何角色人物的外观、动作、服饰，仅聚焦场景空间环境本身。若需要人物提供尺度参照，使用"一名普通群众角色"等泛化描述（不特指剧情角色）。**三宫格各视图描述中同样禁止出现非群众角色** |
| 参考图范围 | 默认添加角色/道具参考图来辅助风格一致性 | **images 数组中严禁包含角色参考图（角色参考图/）和道具参考图（道具参考图/）**。场景参考图仅需场景采样图和风格参考图作为视觉参考，角色和道具的视觉特征与场景空间环境无关，引入后会干扰生图模型对场景的独立理解 |

## 场景间描述差异化原则（重要）

多个场景可能共用相同的地理位置（如不同时代但同一片长江江面），**必须防止不同场景的 prompt 中出现重复的短语或句式**：

| 风险 | 错误做法 | 正确做法 |
|------|---------|---------|
| 地理描述重复 | 所有场景都写"江面宽达二三里"、"巨轮穿梭" | 每个场景只提取其**独有的**地理/时代特征，跳过在多个场景间重复出现的描述词 |
| 句式结构雷同 | 所有场景都用"X位于Y，Z如何如何"开头 | 每个场景的开篇从不同角度切入——空间、时代、光线、氛围各选其一作为首句焦点 |
| 关键元素复制 | 将场景设定中的关键元素表逐条翻译进 prompt | 从关键元素中提取最高优先级的 1-2 个核心特征深入描述，而非罗列清单 |

**核心思想**：每个场景的 prompt 应像一篇独立的环境描写，让读 prompt 的人能感知到这是不同的场景，而不是同一个模板换了个名字。

### 风格类型自适应规则

根据从 全局设定.md 提取的 style_desc 判断视觉风格类型：

| 风格类型 | 判断依据（style_desc 包含以下关键字） | 参考图遵循策略 |
|---------|-----------------------------------|--------------|
| 写实风格 | 写实、真实、影视级、照片级、超清、8K、写实摄影、电影级 | 严格遵循参考图的**构图、空间布局、建筑风格、色调色温**所有维度 |
| 非写实风格 | Q版、Chibi、卡通、乙烯基玩具、哑光塑料、可爱、3D渲染、手绘、赛璐璐、水墨 | 仅参考**构图与空间布局**（空间关系），视觉风格（色调、色温、渲染质感）遵从 style_desc |

**判断逻辑**：检查 style_desc 中是否包含以上关键字。不含任何关键字时默认写实风格。

## 视觉风格提取

Run prompt 构建前，从全局设定中提取视觉风格描述：

1. 读取 `project/{项目名}/全局依赖/全局设定.md`（或 `全局设定/` 下的画风文件）
2. 提取**视觉风格关键字**：如"影视级写实摄影"、"手绘赛璐璐卡通"、"3D 渲染皮克斯风格"、"水墨淡彩"等
3. 将提取到的风格描述记为 `{style_desc}`，用于模板中

> **无全局设定时**：退而求其次从 `前期采样/风格/` 中的参考图文件名判断风格倾向。仍无法判断时使用"超写实影视级画面"。

## Prompt 模板

Prompt 必须严格使用下方模板，逐字替换占位符（string0~string8）和风格占位符（style_desc）。

```
{string0}，
生成一张实景环境空间展示图，左边为一张1:1比例的空间垂直俯瞰（展示大约400平米空间即可，在左上角标明北向，在图中用箭头标记角色所在位置箭头方向为角色面向的方向，不加入文字标注），右侧为3行1列等比的三宫格（第一行：从正面拍摄角色所在位置的120°超广角视图，第二行：从反面拍摄角色所在位置的120°超广角视图，第三行：3.1为从左侧拍摄角色所在位置的视图，3.2为从右侧拍摄角色所在位置的视图，严格保证各个视图都是对该空间整体的一致性还原，严禁出现任何非群众角色），每张图左上角用英文小字标明各视图的名称。
{style_desc}，{string1}，1K分辨率，极致细节，照片级真实质感，镜头语言{string2}。
{string3}，
{string4}，
{string5}，
{string6}，
{string7}，
{string8}.
```

## 参数说明

| 参数 | 含义 | 说明 |
|------|------|------|
| style_desc | 视觉风格 | 从全局设定提取的风格描述，如"影视级写实摄影"、"手绘赛璐璐卡通风格" |
| string0 | 一致性引导词 | 由 global.md 的模式判断确定。**写实风格**: 严格遵循参考图所有维度；**非写实风格**: 仅参考构图与空间布局 |
| string1 | 时代/风格标识 | 如"明朝东方古典建筑与江景" |
| string2 | 镜头语言 | 如"焦点精准、场景纵深强烈" |
| string3 | 空间整体描述 | 场景所在环境的综合描述——空间尺度（约400平米范围）、天际线、水域/地形等，≥80字 |
| string4 | 核心特征 | 核心建筑/场景主体的特征描述，含关键细节，作为空间整体一致性还原的视觉锚点，≥60字 |
| string5 | 氛围/基调 | 如"厚重威严、壮志昂扬的大明盛世气象"，≥40字 |
| string6 | 光线与色彩 | 如"晨光熹微，暖金黄/橙红色调，逆光勾勒船帆轮廓，江面波光粼粼"，≥60字 |
| string7 | 天气与氛围 | 天气条件与整体环境氛围，≥60字。**禁止套用前/中/远景的景别层次结构** |
| string8 | 整体质感 | 与 style_desc 风格一致的质感描述，如"影视级写实摄影，空气透视与颗粒质感" |

## images 数组约束

images 数组**仅允许**包含以下类型的参考图，**禁止**混入任何角色参考图或道具参考图：

| 允许的类型 | 来源路径 | 说明 |
|-----------|---------|------|
| 场景采样图 | `前期采样/场景/{场景名}*.png` | 模式 A 下必须包含，位于 images[0] |
| 风格参考图 | `前期采样/风格/*.png` | 所有模式必须包含至少 1 张 |

**禁止的类型（无论何种模式，均不得加入 images 数组）：**
- 角色参考图：`全局依赖/角色参考图/*.png`
- 道具参考图：`全局依赖/道具参考图/*.png`
- 其他项目资产的参考图

**原因**：场景参考图的唯一目的是刻画场景空间环境本身。引入角色或道具的视觉特征会干扰生图模型对场景的独立理解，导致构图偏向于展示角色/道具而非空间环境。

## Schema 校验

调用 `scripts/validators.py` 的两个函数进行校验：

**顶层固定值（不可变）：**
- `model` **必须固定为** `"gpt-image-2"`
- `imageSize` **必须固定为** `"1K"`
- `aspectRatio` **必须固定为** `"2:1"`

**任务级校验** — `validate_tasks(tasks)`：

| 校验项 | 说明 |
|------|------|
| 基础字段 | prompt, imageSize, aspectRatio, filename, images |
| 类型 | imageSize **必须固定为** `1K`，aspectRatio **必须固定为** `2:1` |
| images/模式 | 至少 1 张参考图（场景采样图或风格参考图） |
| images/范围 | **images 中不得包含角色参考图路径（角色参考图/）或道具参考图路径（道具参考图/）**，仅允许场景采样图（前期采样/场景/）和风格参考图（前期采样/风格/） |
| prompt | 无占位符，必须包含「三宫格」或（「俯瞰」+「北向」）或（「环境空间展示图」+「1:1」），长度 ≥ 50 |
| filename | 必须以 .png 结尾 |

**顶层校验** — `validate_top_level(data)`：
- `model` **必须固定为** `"gpt-image-2"`
- `output_path` 非空
- `tasks` 存在
