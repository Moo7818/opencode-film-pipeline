# 全局基础参考流程

> 共享定义（Prompt 模板、参数表、校验规则）见 `rules/common.md`。

## 触发条件

- 阶段：Phase 2 — 全局视觉资产生成
- 输入：全局设定 + 角色设定 + 前期采样（人物/风格）

## 执行步骤

### 步骤 1：收集输入文件

定位并读取以下文件：

| 文件 | 用途 |
|------|------|
| `project/{项目名}/全局依赖/全局设定.md` | 画风参考、色调色温、视觉语言标准 |
| `project/{项目名}/全局依赖/角色设定/角色设定.md` | 角色名、性别、年龄、视觉特征、气质/性格、定位 |
| `project/{项目名}/前期采样/人物/{角色名}*.png` | 角色参考图（可选，决定模式 A/B） |
| `project/{项目名}/前期采样/风格/*.png` | 风格参考图（所有角色共用） |

### 步骤 2：模式判断

| 模式 | 条件 | 参考图 |
|------|------|--------|
| **模式 A** | `前期采样/人物/{角色名}*.png` 存在 | 人物参考图 + 风格参考图 |
| **模式 B** | `前期采样/人物/{角色名}*.png` 不存在 | 仅风格参考图 |

### 步骤 3：构建 Prompt

使用 `rules/common.md` 中的 **Prompt 模板**和**参数说明**逐字替换占位符。

**全局模式专属参数定义：**

- **string0**（一致性引导词）：模式 A 为 `"人物特征严格参考图片1-图片n"`，模式 B 为空字符串（无一致性引导词，直接接 string1）
- **string3/string4/string5**：从 `角色设定.md` 提取
- **string8/string9/string10**：从 `角色设定.md` 详细扩展

其余参数按 `rules/common.md` 参数表说明填充。

### 步骤 4：生成任务 JSON

输出到 `project/{项目名}/全局依赖/角色参考图/角色参考图_任务表.json`

```json
{
  "model": "gpt-image-2",
  "tasks": [
    {
      "prompt": "{string0}，{string1}，8K中超清...",
      "imageSize": "1K",
      "aspectRatio": "16:9",
      "filename": "{角色名}_基准.png",
      "images": [
        "project/{项目名}/前期采样/人物/{角色名}.png",
        "project/{项目名}/前期采样/风格/{风格文件}.png"
      ]
    }
  ],
  "output_path": "project/{项目名}/全局依赖/角色参考图/"
}
```

**自检清单（每一项必须通过）：**
- □ tasks 数量等于角色数量（每个角色有且仅有 1 个 task）
- □ 每个 task 的 prompt 严格遵循模板格式，包含"四视图排版"和"右侧并列展示人物全身正面、全身侧面、全身背面"字样，而非单视图描述
- □ string1 已根据角色视觉风格类型从「string1 质感类型选择表」中正确选择
- □ mode_A（前期采样有人物图）：每个 task 的 `images` 字段非空，已添加对应人物参考图和风格参考图
- □ mode_B（前期采样无人物图）：已添加风格参考图

### 步骤 5：Schema 校验

按 `rules/common.md` 中 **Schema 校验** 说明执行：

1. 先调用 `validate_top_level(data)` 校验顶层字段
2. 再调用 `validate_tasks(tasks, "mode_A")` 或 `validate_tasks(tasks, "mode_B")` 校验任务列表

两个函数均返回空列表则校验通过。

### 步骤 6：输出完成提示

使用 `rules/common.md` 中的完成提示。

## 参考图上传顺序

### 模式 A（有人物参考图）

| 位置 | 内容 |
|------|------|
| images[0] | 人物参考图（`前期采样/人物/{角色名}*.png`） |
| images[1] | 风格参考图（`前期采样/风格/*.png`） |

### 模式 B（无人物参考图）

| 位置 | 内容 |
|------|------|
| images[0] | 风格参考图（`前期采样/风格/*.png`） |
