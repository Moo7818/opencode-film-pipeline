# 群像参考流程

> 共享定义（Prompt 模板、参数表、校验规则）见 `rules/common.md`。

## 触发条件

- 阶段：Phase 2 — 全局视觉资产生成（群组阶段）
- 时序：与个体角色参考并行或在其后
- 输入：群组设定 + 成员设定 + 风格参考

## 执行步骤

### 步骤 1：收集输入文件

定位并读取以下文件：

| 文件 | 用途 |
|------|------|
| `project/{项目名}/全局依赖/角色设定/角色设定.md` | 角色及群组清单 |
| `project/{项目名}/全局依赖/角色设定/具体设定/{群组名}.md` | 群组详细设定 |
| `project/{项目名}/全局依赖/角色设定/具体设定/{各成员角色名}.md` | 各成员详细设定 |
| `project/{项目名}/前期采样/风格/*.png` | 风格参考图 |

### 步骤 2：提取群组信息

从群组设定和成员设定文件中提取以下信息：

| 信息项 | 来源 | 说明 |
|--------|------|------|
| 角色数量 | 群组设定 - 成员列表 | 群组成员总数 |
| 角色列表及特征 | 各成员设定文件 | 每位角色的排布顺序 + 关键视觉特征（发型、上装、下装、鞋履、配饰） |
| 排布顺序 | 按主次 / 身份确定 | 左起依次排列，C位为最重要角色 |
| C位角色 | 群组设定 - C位信息 | 居中角色的视觉突出描述 |
| 群组整体定位 | 群组设定 - 整体定位 | 群组的身份 / 角色定位描述 |
| 背景色 | 群组设定 - 背景色 | 纯色背景颜色，默认"浅灰色" |

### 步骤 3：构建 Prompt

使用 `rules/common.md` 中的**群像专用 Prompt 模板**，填入参数。

**群像模式专属参数定义：**

- **string0**（一致性引导词）：若有风格参考图则写 `"风格严格参考图片1"`，否则为空字符串
- **string1/string2/string6/string11/string12**：从 `rules/common.md` 参数表和角色设定/风格参考提取
- **群组-角色数量 / 群组-角色列表及特征 / 群组-C位描述 / 群组-整体定位描述 / 群组-背景色**：从群组设定中提取

### 步骤 4：生成任务 JSON

输出到 `project/{项目名}/全局依赖/角色参考图/群像参考图_任务表.json`

```json
{
  "model": "gpt-image-2",
  "tasks": [
    {
      "prompt": "{完整渲染的 Prompt}",
      "imageSize": "1K",
      "aspectRatio": "16:9",
      "filename": "{群组名}_基准.png",
      "images": [
        "project/{项目名}/前期采样/风格/{风格文件}.png"
      ]
    }
  ],
  "output_path": "project/{项目名}/全局依赖/角色参考图/"
}
```

**自检清单（每一项必须通过）：**
- □ tasks 数量为 1（群像模式只生成 1 张群像参考图）
- □ prompt 已使用群像专用模板，包含"角色群像设定图，团队阵容展示"和"并排站立"字样，而非四视图描述
- □ string1 已根据视觉风格类型从「string1 质感类型选择表」中正确选择
- □ 所有 `{群组-` 前缀占位符均已替换，无残留模板标记
- □ `images` 字段已添加风格参考图（至少 1 张）
- □ prompt 末尾包含"服装上没有任何文字、logos、标签或文字标识，no text，no logo"

### 步骤 5：Schema 校验

按 `rules/common.md` 中 **Schema 校验** 说明执行：

1. 先调用 `validate_top_level(data)` 校验顶层字段
2. 再调用 `validate_tasks(tasks, "group")` 校验任务列表

两个函数均返回空列表则校验通过。

### 步骤 6：输出完成提示

```
任务 JSON 已生成，等待 Art-director 执行生图
```
