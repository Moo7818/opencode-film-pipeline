# 剧集级参考流程

> 共享定义（Prompt 模板、参数表、校验规则）见 `rules/common.md`。
> 本模式**只读**妆造衣橱，不自行生成角色参考图。

## 触发条件

- 阶段：剧集级参考图 + 资产同步（episode_character_ref + asset_sync）
- 输入：分镜脚本 + 妆造衣橱 + 角色设定

## 核心职责

episode 模式**不生成 task JSON**。它的职责是：

1. 从分镜脚本提取每场戏中角色的妆造名
2. 查询妆造衣橱，匹配已有资产
3. 输出**妆造匹配清单**（供 coordinator 执行资产同步）
4. 发现衣橱中不存在的新妆造时，向 orchestrator 报告

> 妆造的**生成**由 global 模式负责（`rules/global.md` 步骤 3c）。episode 模式只做匹配与报告。

## 步骤 1：收集输入文件

定位并读取以下文件：

| 文件 | 用途 |
|------|------|
| `project/{项目名}/{剧集号}/分镜/分镜脚本.json` | 提取该集角色出场及妆造名标注 |
| `project/{项目名}/全局依赖/角色设定/妆造衣橱.md` | 只读查询：角色已有的妆造资产清单 |
| `project/{项目名}/全局依赖/角色设定/角色设定.md` | 角色清单 |
| `project/{项目名}/全局依赖/角色设定/具体设定/{角色名}.md` | 角色详细设定（含造型设计，用于新妆造判定） |

## 步骤 2：提取妆造名

逐场扫描分镜脚本，为每个出场角色确定该场使用的妆造名。

### 提取规则

1. 扫描每场戏中所有镜头的 `场景描述` 和 `站位/调度` 字段
2. 查找 `[妆造:名]` 标注，提取妆造名
3. 同一角色在同一场戏中多次出现但无新标注 → 使用该场首次提取的妆造名
4. 同一角色在不同场戏中有不同标注 → 各场分别记录

### 缺省规则

- 角色出场但**无** `[妆造:名]` 标注 → 妆造名默认为 `默认`
- 角色在分镜脚本中完全未出场 → 不列入该集匹配清单

### 提取结果

整理为角色×场级别的妆造需求列表：

```
角色A → 第1场: 默认, 第3场: 战斗铠甲, 第5场: 默认
角色B → 第1场: 默认, 第2场: 默认
角色C → 第3场: 夜行衣
```

> 同一角色在同一集中使用的不同妆造名去重后，得到该角色的**本集妆造需求集合**。

## 步骤 3：查询妆造衣橱

读取 `妆造衣橱.md`，对步骤 2 提取的每个 (角色, 妆造名) 组合进行匹配。

### 匹配逻辑

对每个 (角色, 妆造名)：

| 衣橱状态 | 处理方式 |
|---------|---------|
| **已存在且已生成**（✅） | 记录参考图文件名，列入匹配清单 |
| **已存在但待生成**（⏳） | 记录为"待生成"，列入匹配清单（orchestrator 会确保先生成再同步） |
| **不存在** | 进入步骤 4：新妆造判定 |

### 匹配结果示例

```
角色A × 默认        → ✅ 已生成 → {角色A}_默认.png
角色A × 战斗铠甲     → ✅ 已生成 → {角色A}_战斗铠甲.png
角色B × 默认        → ✅ 已生成 → {角色B}_默认.png
角色C × 夜行衣      → ❌ 衣橱中不存在 → 进入步骤 4
```

## 步骤 4：新妆造判定

当衣橱中不存在该妆造名时，Agent 需判断是否应作为新妆造报告给 orchestrator。

### 判定原则

**只认"换了一套衣服"，不认"同一套衣服的不同状态"。**

触发新妆造的条件是——该差异会导致角色在生图中呈现明显不同的视觉身份。如果观众一眼能看出"这是另一套造型"，则触发；如果观众觉得"还是那套衣服只是姿态不同"，则不触发。

### 判定标准

Agent 阅读分镜脚本中该角色的画面描述，与角色设定「造型设计」中已有的妆造进行对比：

| 差异类型 | 是否触发新妆造 | 示例 |
|---------|--------------|------|
| **整体服装品类变化** | ✅ 触发 | 便装→铠甲、常服→礼服 |
| **核心配饰增减** | ✅ 触发 | 佩戴/摘除面具、披风、头盔 |
| **发型/头饰整体变化** | ✅ 触发 | 散发→束发、戴冠/摘冠 |
| **颜色变化** | ⚠️ 视情况 | 同款换色不触发，主色调明显不同则触发 |
| **局部破损/污渍** | ❌ 不触发 | 衣角磨损、袖口脏污 |
| **细微动作导致的形变** | ❌ 不触发 | 衣摆飘起、袖子卷起 |
| **配饰微调** | ❌ 不触发 | 腰带位置变化、领口开合 |
| **光影/氛围差异** | ❌ 不触发 | 暖光下的衣服 vs 冷光下的衣服 |

### 判定结果

| 判定结果 | 处理方式 |
|---------|---------|
| **符合触发标准** | 报告为新妆造需求（步骤 5），该 (角色, 妆造名) 标记为"待生成" |
| **不符合触发标准** | 归入最接近的已有妆造，不报告。匹配清单中使用被归入的已有妆造名 |

> **归入示例**：角色A穿"微脏的校服"出现在某场，分镜中标注 `[妆造:脏校服]`，但衣橱中无此条目。Agent 判定"局部污渍"不触发新妆造 → 归入"默认"妆造，匹配清单中该场使用 `{角色A}_默认.png`。

### 数量审查

若报告新妆造后该角色的衣橱总数将超过 5 套（含默认），在报告中附注提醒：

```
⚠️ 角色{角色名}妆造数将达{N}套，建议审查是否可合并相似妆造
```

> 此提醒不阻断流程，由 orchestrator 决定是否采纳。

## 步骤 5：输出妆造匹配清单

将匹配结果写入 `project/{项目名}/{剧集号}/角色参考图/妆造匹配清单.json`。

```json
{
  "剧集号": "{剧集号}",
  "匹配结果": [
    {
      "角色名": "{角色名}",
      "本集妆造需求": [
        {
          "妆造名": "默认",
          "使用场次": [1, 5],
          "衣橱状态": "已生成",
          "参考图文件": "{角色名}_默认.png",
          "参考图路径": "project/{项目名}/全局依赖/角色设定/角色参考图/{角色名}_默认.png"
        },
        {
          "妆造名": "战斗铠甲",
          "使用场次": [3],
          "衣橱状态": "已生成",
          "参考图文件": "{角色名}_战斗铠甲.png",
          "参考图路径": "project/{项目名}/全局依赖/角色设定/角色参考图/{角色名}_战斗铠甲.png"
        }
      ]
    }
  ],
  "新妆造需求": [
    {
      "角色名": "{角色名}",
      "妆造名": "{妆造名}",
      "使用场次": [3],
      "判定依据": "整体服装品类变化：便装→夜行衣",
      "建议造型描述": "从分镜脚本画面描述提取的简要造型描述",
      "数量提醒": null
    }
  ]
}
```

### 字段说明

| 字段 | 说明 |
|------|------|
| 匹配结果 | 该集所有出场角色的妆造匹配情况，供 coordinator 执行资产同步 |
| 本集妆造需求 | 该角色在本集使用的所有妆造，去重后列出 |
| 使用场次 | 该妆造被使用的场号列表 |
| 衣橱状态 | `已生成` / `待生成` |
| 参考图路径 | 衣橱中对应资产的完整路径（待生成的填预期路径） |
| 新妆造需求 | 需要报告给 orchestrator 的新妆造列表 |
| 判定依据 | Agent 判定该妆造为"新妆造"的依据（引用变化判定标准） |
| 建议造型描述 | Agent 从分镜脚本提取的简要造型描述，供 orchestrator 决策参考 |
| 数量提醒 | 超过 5 套时的审查提醒，否则为 null |

### 无新妆造时

如果该集所有妆造均在衣橱中存在（或不符合触发标准已归入已有妆造），`新妆造需求` 为空数组 `[]`。

## 步骤 6：报告给 orchestrator

### 有新妆造需求时

Agent 在输出完成后，向 orchestrator 报告：

```
剧集 {剧集号} 妆造匹配完成。
- {N} 个角色，{M} 个妆造已匹配衣橱资产
- 发现 {K} 个新妆造需求：{角色名}/{妆造名}（{判定依据}）
请 orchestrator 决定是否加入衣橱并触发 global 模式生成。
```

### 无新妆造需求时

```
剧集 {剧集号} 妆造匹配完成。
- {N} 个角色，{M} 个妆造全部匹配衣橱已有资产
- 无新妆造需求
coordinator 可直接执行资产同步。
```

## 步骤 7：输出完成提示

```
妆造匹配清单已生成，等待 orchestrator 处理新妆造需求（如有）及 coordinator 执行资产同步
```

## 与其他模式的关系

| 维度 | global 模式 | episode 模式（本文件） |
|------|-----------|----------------------|
| 触发阶段 | 全局视觉资产生成 / 新妆造时 | 剧集级参考图 + 资产同步（episode_character_ref + asset_sync） |
| 衣橱关系 | 初始化写入 + 新妆造写入 | **只读**查询 |
| 产出物 | task JSON（供 art-director 生图） | 匹配清单 JSON（供 coordinator 同步） |
| 是否生成图片 | 是（通过 art-director） | **否** |
| 妆造名来源 | 角色设定「造型设计」 | 分镜脚本 `[妆造:名]` 标注 |
| 参考图引用 | Tier 1 选角资产 | 衣橱中的 Tier 2 妆造资产 |
