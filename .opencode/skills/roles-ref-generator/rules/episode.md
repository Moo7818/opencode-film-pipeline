# 剧集级参考流程

> 共享定义（Prompt 模板、参数表、校验规则）见 `rules/common.md`。

## 触发条件

- 阶段：Phase 3 — 按集推进（分镜脚本已生成）
- 输入：分镜脚本 + 场景设定 + 全局基准资产

## 执行步骤

### 步骤 1：收集输入文件

定位并读取以下文件：

| 文件 | 用途 |
|------|------|
| `project/{项目名}/{剧集号}/分镜/分镜脚本.json` | 提取该集角色出场信息 |
| `project/{项目名}/全局依赖/全局设定.md` | 画风参考、色调色温、视觉语言标准 |
| `project/{项目名}/全局依赖/角色设定/角色设定.md` | 角色名、性别、年龄、视觉特征、气质/性格、定位 |
| `project/{项目名}/全局依赖/角色参考图/{角色名}_基准.png` | 全局基准资产（作为参考图） |
| `project/{项目名}/全局依赖/场景设定/场景设定.md` | 场景色调、光影风格（可选） |

### 步骤 2：模式判断

剧集级参考固定为 **模式 B**（无人物采样图，仅使用全局基准资产作为参考）。

| 模式 | 条件 | 参考图 |
|------|------|--------|
| **模式 B** | 固定模式 | 全局基准资产 + 风格参考图 |

注：validator 调用时使用 `"episode"` 模式（非 `"mode_B"`），以启用更严格的 images 校验。

### 步骤 3：剧集变化检测

分析分镜脚本中该集角色的描述，与全局角色设定进行比较，判断是否需要生成剧集专属参考图。

#### 判断方法

你（Agent）自行阅读分镜脚本中的画面描述和表演/微表情字段，与全局角色设定中的视觉特征进行对比。重点关注以下变化：

| 变化类型 | 说明 | 示例 |
|---------|------|------|
| 服装变化 | 盔甲/夜行衣/礼服/婚服等与全局设定不同 | 全局为常服，本集穿夜行衣 |
| 年龄变化 | 少年→成年等 | 回忆篇中角色更年轻 |
| 身体状态变化 | 受伤、虚弱、变身 | 右臂绑绷带、脸上有伤 |
| 关键剧情装扮 | 潜入、战斗、婚礼、登基 | 特定场景的特殊着装 |

#### 触发条件

**满足任一条件即生成**剧集级参考图任务：

- 分镜脚本中角色的服装描述与全局设定明显不同
- 角色有特殊身体状态（受伤、变身等）
- 角色有年龄变化
- 关键剧情需要特殊装扮

#### 无变化时

如果分镜脚本中角色的视觉呈现与全局基准资产一致，**不生成任务**，直接复用全局基准资产。

### 步骤 4：构建 Prompt

使用 `rules/common.md` 中的 **Prompt 模板**和**参数说明**逐字替换占位符。

**剧集模式专属参数定义：**

- **string0**（一致性引导词）：固定为 `"人物特征严格参考图片1"`
- **string3/string4/string5**：从分镜脚本画面描述提取，**覆盖**全局角色设定中的对应字段
- **string8/string9/string10**：基于全局角色设定 + 分镜脚本变化，重点描述本集差异

其余参数按 `rules/common.md` 参数表说明填充。

### 步骤 5：生成任务 JSON

输出到 `project/{项目名}/{剧集号}/角色参考图/角色参考图_任务表.json`

```json
{
  "model": "gpt-image-2",
  "tasks": [
    {
      "prompt": "{string0}，{string1}，8K中超清...",
      "imageSize": "1K",
      "aspectRatio": "16:9",
      "filename": "{角色名}_{剧集号}集.png",
      "images": [
        "project/{项目名}/全局依赖/角色参考图/{角色名}_基准.png",
        "project/{项目名}/前期采样/风格/{风格文件}.png"
      ]
    }
  ],
  "output_path": "project/{项目名}/{剧集号}/角色参考图/"
}
```

**自检清单（每一项必须通过）：**
- □ tasks 数量等于需生成的角色数量（只有检测到变化的角色才生成 task）
- □ 每个 task 的 prompt 严格遵循模板格式，包含"四视图排版"和"右侧并列展示人物全身正面、全身侧面、全身背面"字样，而非单视图描述
- □ string1 已根据角色视觉风格类型从「string1 质感类型选择表」中正确选择
- □ 每个 task 的 `images` 字段非空，已添加全局基准资产和风格参考图

### 步骤 6：Schema 校验

按 `rules/common.md` 中 **Schema 校验** 说明执行：

1. 先调用 `validate_top_level(data)` 校验顶层字段
2. 再调用 `validate_tasks(tasks, "episode")` 校验任务列表

两个函数均返回空列表则校验通过。

### 步骤 7：输出完成提示

使用 `rules/common.md` 中的完成提示。

## 参考图上传顺序

| 位置 | 内容 |
|------|------|
| images[0] | 全局基准资产（`全局依赖/角色参考图/{角色名}_基准.png`） |
| images[1] | 风格参考图（`前期采样/风格/*.png`） |

**参考图用途界定：**
- 全局基准资产提供：面部骨相特征、五官细节、发型结构、气质神态
- **禁止从参考图推断服装**：服装必须从分镜脚本提取（覆盖全局设定）

## 差异对比

| 维度 | 全局基础参考 | 剧集级参考 |
|------|-------------|-----------|
| 触发阶段 | Phase 2 — 全局视觉资产生成 | Phase 3 — 按集推进 |
| 核心输入 | 角色设定 + 前期采样 | 分镜脚本 + 场景设定 |
| 参考图来源 | `前期采样/人物/` | 全局基准资产 |
| 服装来源 | 角色设定中的视觉特征 | 分镜脚本画面描述（覆盖） |
| 风格来源 | 全局设定画风参考 | 全局 + 场景色调叠加 |
| 视图数 | 四视图 | 四视图 |
| 输出路径 | `全局依赖/角色参考图/角色参考图_任务表.json` | `{剧集号}/角色参考图/角色参考图_任务表.json` |
| 文件名 | `{角色名}_基准.png` | `{角色名}_{剧集号}集.png` |
